没有打包 SDK、JDK、Gradle、完整 Maven 缓存或 Git 历史。已有工具链可复用；换机首次构建可能需要下载 Maven 依赖。**这不是全工具链离线镜像**。内核压缩文件、对应源码及 PC 测试服务随包提供，`setup-core.cjs` 会校验并生成 APK 所需目录。不要单独移动 `android/` 后丢掉同级 `resources/`。

不包含手机数据备份、用户账号、真实订阅、控制令牌、运行配置、签名私钥和桌面未完成改动。输入辅助 JAR 是测试工具，不随产品 APK 安装。

## 3. 已实现功能

- 主页进入实例 1 / 2。两个独立进程在 WebView 初始化前设置不同数据目录后缀，Cookie、localStorage、网址和代理各自保留。
- 每实例有手动无认证 HTTP/SOCKS5 代理入口、独立节点库、独立 Mihomo 子进程；通过回环代理让 WebView 使用当前节点。
- 可粘贴节点分享链接、含 `proxies` 的 YAML/JSON 或 Base64 订阅内容。支持常见 SS、VMess、VLESS、Trojan、Hysteria2、TUIC、AnyTLS、SOCKS5 链接；HTTP 节点可从 YAML/JSON 导入。解析支持不等于各协议已连通验收。
- 订阅下载可选择系统网络或当前实例代理，不自动换下载网络。导入只增加节点，用户选中后才启用。
- 内核端口随机且仅监听回环，控制器随机令牌；内核失败时阻止该实例继续加载，不自动回退直连。
- 节点导入限制 2 MiB / 500 节点，白名单参数，忽略订阅 DNS/TUN/规则等顶层配置；拒绝外部插件与链式节点。
- 有内核最近 100 条阶段记录，尚无完整诊断导出。

## 5. 接手顺序

1. 解压到新的目录，执行根目录 `校验交接包.ps1`。先读本文，再读 [开发文档](开发文档.md)。
2. 配置自己的 SDK/JDK/Gradle 路径，按开发文档构建；源码不用放到原开发机的固定路径。
3. 先在测试设备安装并验证双实例，不要把正式账号数据导入测试原型。已有安装必须先确认签名是否相同；签名不同不能覆盖安装，不能直接卸载来绕过。
4. 跑单元测试和 APK 资源校验，再在可清理的原型安装中跑真机测试。基础 smoke 会改代理/网址、写测试站点存储并停止原型；不应用于存有正式账号的环境。
5. 开发前建立自己的 Git 仓库或检查点，修改后保留对比和测试报告。本 ZIP 没有原仓库 Git 历史。

这些是待办，未作为已完成功能交付：

1. **网络矩阵与诊断**：验证 Android 9/12/新系统和新旧 WebView；认证代理、真实 HTTPS、公网节点、VPN/TUN 组合；增加脱敏诊断导出和链路阶段说明。
2. **基本可用性**：完整节点编辑/删除、文件导入、订阅管理及更新、实例命名、可见运行状态；保存格式加版本和迁移测试。
3. **实例规模与生命周期**：设计多实例进程槽位、内存上限、后台恢复。现在固定 2 个进程，不能仅复制条目宣称支持任意数量。
4. **再做指纹方案**：先列 WebView 可控制与不可控制的字段，做一致性验证，再决定系统 WebView 方案或独立浏览内核。当前没有桌面版的指纹配置和扩展能力，不能照搬 Electron 注入。
5. **正式发行**：独立管理签名、设备兼容性、应用商店与开源许可审查、更新和隐私说明。签名私钥由项目所有者保管。

## 7. 必须保留的边界和历史教训

- WebView 数据目录、代理覆盖是按进程设置；新建 WebView 前必须设置后缀。两个实例仍是同一包名、同一应用 UID，不是互相对抗的独立 Android 安全沙箱。
- 这不是系统 TUN。HTTP 失败不回退已测；DNS/WebRTC/UDP 全路径无泄露未测，不能作保证。`dns.enable=false` 只是不开内核 DNS 服务，不表示网络完全不使用 DNS。
- 订阅“系统网络”使用 `Proxy.NO_PROXY`，不继承实例代理，也不额外使用 Wi-Fi HTTP 代理；手机 VPN/TUN 仍可接管。
- 取消在保存前阻止入库；已发出的下载可持续到响应或超时，进入提交阶段后不能冒充已取消。
- localStorage 异步写盘，真机测试等待 6.5 秒后强停；瞬间断电/强杀时最新写入仍可能丢失。
- 手机可回收后台进程。不要描述为所有网页/视频/活动永远保持运行。
- APK 内核必须从安装后的 `nativeLibraryDir` 执行；Android 10 起不能沿用可写目录解压再执行的路线。
- 升级内核必须同步版本、哈希、就绪检查和源码许可资源；`.tar.gz` 资产曾被 AAPT 自动解压改名，现用 `.tgz` 保持源码原字节。
- SELinux 曾拦截 shell/run-as 直接杀内核；测试使用 debug 专用接收器，不要关闭 SELinux、root 手机或把接收器放进正式包。
- WebView 99 不支持 Playwright 桌面 context 管理，当前脚本连接页面 CDP。中文输入法曾改写 `adb input text`，改用 UiAutomator 填框；无需修改用户输入法。

## 8. 数据保留与回滚

运行数据仅位于手机本包私有目录，详见开发文档。包内没有真实运行数据。不要复制这些数据进入 Git、报告或其他人的手机。

原仓库历史：初版 `6351d31`，内核前检查点 `073ee2f`，当前功能基线 `4860688`。在原仓库回滚时仅针对 Android 相关提交审查并 revert，不对整个桌面仓库执行硬重置。接手包可重新解压为只读原始快照，与工作目录分开保存。

本 APK 使用原开发机调试签名；新机器自动生成的调试签名通常不同。没有携带调试私钥，无法保证新构建能直接覆盖原安装。需要原签名或确认备份后另行规划迁移；不要承诺任意降级能保留全部数据。卸载本包会清除本包的数据。
