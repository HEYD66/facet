# 重置实例环境

适用版本：千面 Facet 0.2.16。

「重置环境」会以新实例 ID、新存储分区和新随机环境重建实例，仅保留名称、网络模式、节点副本及订阅来源关联。支持单个或批量重置。

备注、自启动、音量、扩展启用状态和网页地址恢复新实例默认值。旧登录状态及网页数据不会被带入新分区；网站或扩展之后可能重新生成访客 Cookie。

重置前停止旧实例。新代理副本保存和校验通过后才替换实例记录；替换前失败保留旧记录与浏览数据。替换后清理旧分区，被系统占用的目录可能延迟到下次启动清理，新实例不会再使用旧分区。

此操作不能恢复已删除的登录资料。新 ID 对外生效，旧 ID 失效；单次 API 返回 `oldId`/`id`，批量结果包含 `newId`，外部脚本应采用新 ID。AI 工具会更新当前任务的授权实例 ID。
