# 重置实例环境

v0.2.17：重置保留扩展启用列表，并按实测出口同步语言和时区。

「重置环境」会以新实例 ID、新存储分区和新随机环境重建实例，保留名称、网络模式、节点副本、订阅来源关联及原扩展启用列表。支持单个或批量重置。

备注、自启动、音量和网页地址恢复新实例默认值。旧登录状态及网页数据不会被带入新分区；网站或扩展之后可能重新生成访客 Cookie。

先通过所选代理（直连实例使用直连）查询出口国家与时区，再停止旧实例。查询失败保留旧实例与数据，不使用默认地区或直连兜底。扩展仅迁移启用关系，不复制旧分区里的扩展配置、登录或缓存。新代理副本保存和校验通过后才替换实例记录；替换前失败保留旧记录与浏览数据。替换后清理旧分区，被系统占用的目录可能延迟到下次启动清理，新实例不会再使用旧分区。

此操作不能恢复已删除的登录资料。新 ID 对外生效，旧 ID 失效；单次 API 返回 `oldId`/`id`，批量结果包含 `newId`，外部脚本应采用新 ID。AI 工具会更新当前任务的授权实例 ID。
