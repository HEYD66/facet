# 内置 AI 助手

适用版本：千面 Facet 0.2.16。

## 开始使用

点击顶部「AI」展开右侧面板，进入「设置」填写兼容 Chat Completions 的接口地址、模型和密钥。可点击「一键获取模型」，也可手填模型名称。支持多个提供商，输入区可切换模型；任务执行中不能更换模型。默认配置为空，未配置不会发送请求。

接口通常以 `/v1` 结尾。支持 HTTPS 和本机 HTTP；不接受地址内嵌凭据，不跟随重定向。模型请求走应用本机网络，不跟随浏览实例代理。调用费用由所选服务决定。

## 会话与记忆

- 「会话」查看历史，点击会话标题切换；支持改名和删除确认。
- 「新任务」另开会话，保留旧聊天。最多保存 200 个会话，不自动删除历史。
- 每个会话独立保存消息、已发送图片、压缩摘要和最近操作实例范围，应用重启后恢复。未发送草稿只在本次应用运行期间保留。
- 切换会话不打断任务；同时只允许一个任务执行。返回运行中的会话可以审批或停止，运行中不能删除。
- 历史较长时自动压缩，保留最近两轮完整上下文；摘要可能丢失细节，旧图片不进入压缩摘要。界面最多显示最近 100 条记录。
- 重启只恢复历史，不自动继续任务或恢复旧的完全权限。旧版单会话自动保留为「原有会话」。

## 发送与权限

Enter 发送，Shift+Enter 换行。可粘贴或选择 PNG、JPEG、WebP 图片，每条最多 4 张、单张不超过 5MB；图片理解取决于模型能力。正文支持流式显示。

选择单个或全部实例后发送，任务执行期间授权范围固定。三种权限：

| 模式 | 行为 |
| --- | --- |
| 仅可查看 | 可查询状态、读取网页，禁止修改 |
| 逐项确认 | 修改前显示对象、参数，确认后执行 |
| 完全权限 | 对本次授权范围内支持的操作直接执行，不逐项询问 |

网页内容、图片和会话上下文会发送给选中的模型服务。完全权限不等于无限系统权限；宿主仍检查工具白名单和实例范围。切换提供商后的请求会发送当前会话上下文。

## 能力与边界

支持实例查询、创建、启停、改名、代理分配、环境配置，以及授权实例中的网页读取、导航、点击、填写、滚动、按键、下拉选择和框架操作。管理工具复用千面的已有功能，扩展、备份和文件选择仍受原有权限与原生交互限制。

`show_instance` 切换到指定运行实例，不刷新或重建网页。`read_manual` 读取随应用提供的说明书，`cdp_command` 使用内部 CDP；不需要用户另开外部控制端口。CDP 工具只开放列出的页面与输入命令，不支持任意协议调用。

不支持任意 Windows 桌面控制、任意 JavaScript 执行、密码或文件输入框填写；不承诺所有网站或扩展兼容。点击成功不等于业务完成，应再次读取结果。

任务最多 16 轮。重复结果或空读取达到保护阈值后停止工具执行，并给出已验证结果、未完成部分和下一步。最终说明失败或超过 20 秒时，由千面提供停止说明。主动点击「停止」会取消请求及待确认操作，已执行动作不会自动撤销。

## AI 随机创建实例的工具约定

用户要求随机环境与随机代理时，调用：

```json
{"action":"create","params":{"name":"实例名称","random":true,"start":false}}
```

用户要求打开时才设 `start:true`，可用 `sourceId` 限定已导入节点源。

1. 从可用候选中随机取样，最多尝试 5 个不同节点。没有节点时明确失败，不以直连代替。
2. 实测连通性，通过节点获取出口 IP、国家和 IANA 时区。旧缓存和节点名称不能替代实测。
3. 使用内置方案随机生成环境，语言按实测国家的默认语言、时区按实测结果匹配。
4. 全部候选失败、不完整或配置发生变化时，不创建未经验证的直连替代实例。
5. 检查返回的 `created`、`verified`、`started`、`configurationError`、`startError`。部分失败时先核对返回的实例 ID，不能盲目重建。
6. 随机节点不保证独享或全新 IP，检测通过不保证所有网站永远可访问。

只有明确要求原生、自定义环境或直连时才使用普通 `create`。随机创建成功的新实例加入当前任务范围。

## 本机数据

密钥保存在实际应用数据目录的 `ai-settings.json`；会话保存在 `ai-conversation.json`，使用系统加密与原子写入。系统加密不可用时不降级为明文。跨机器或 Windows 账号迁移可能无法解密。

旧单会话迁移前保留 `ai-conversation.json.pre-sessions.bak` 密文备份，之后的会话变化不会同步到该备份。删除会话移除当前记录，不自动删除迁移备份。恢复备份前请退出应用并另存当前文件；恢复旧备份不会包含之后新增的会话。

保存失败会显示记忆存储异常；读取或解密失败时保留原文件并阻止覆盖，不会因点击新任务而删除损坏文件。不要公开分享这些数据文件。
