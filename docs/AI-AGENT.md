# 内置 AI 助手

适用范围：当前源码工作区；安装包能力以对应发布版本为准。

## 开始使用

点击顶部「AI」展开右侧面板，进入「设置」填写兼容 Chat Completions 的接口地址、模型和密钥。可点击「一键获取模型」，也可手填模型名称。支持多个提供商，输入区可切换模型；任务执行中不能更换模型。默认配置为空，未配置不会发送请求。

每个提供商可勾选「模型支持图片」。勾选后 AI 观察网页时可以按需附带页面截图；未勾选时不会发送截图。

接口通常以 `/v1` 结尾。支持 HTTPS 和本机 HTTP；不接受地址内嵌凭据，不跟随重定向。模型请求走应用本机网络，不跟随浏览实例代理。调用费用由所选服务决定。

## 会话与记忆

- 「会话」查看历史，点击会话标题切换；支持改名和删除确认。
- 「新任务」另开会话，保留旧聊天。最多保存 200 个会话，不自动删除历史。
- 每个会话独立保存消息、已发送图片、压缩摘要和最近操作实例范围，应用重启后恢复。未发送草稿只在本次应用运行期间保留。
- 切换会话不打断任务；同时只允许一个任务执行。返回运行中的会话可以审批或停止，运行中不能删除。
- 历史较长时自动压缩，保留最近两轮完整上下文；摘要可能丢失细节，旧图片不进入压缩摘要。界面最多显示最近 100 条记录。
- 重启只恢复历史，不自动继续任务或恢复旧的完全权限。旧版单会话自动保留为「原有会话」。

## 发送与权限

Enter 发送，Shift+Enter 换行。可粘贴或选择 PNG、JPEG、WebP 图片，每条最多 4 张、单张不超过 5MB；图片理解取决于模型能力。正文支持流式显示。

选择单个或全部实例后发送，任务执行期间授权范围固定。三种权限：

| 模式 | 行为 |
| --- | --- |
| 仅可查看 | 可查询状态、读取网页，禁止修改 |
| 逐项确认 | 修改前显示对象、参数，确认后执行 |
| 完全权限 | 对本次授权范围内支持的操作直接执行，不逐项询问 |

网页内容、图片和会话上下文会发送给选中的模型服务。完全权限不等于无限系统权限；宿主仍检查工具白名单和实例范围。切换提供商后的请求会发送当前会话上下文。

## 能力与边界

支持实例查询、创建、启停、改名、代理分配、环境配置，以及授权实例中的网页观察与操作（见下节）、导航、前进后退和刷新。管理工具复用千面的已有功能，扩展、备份和文件选择仍受原有权限与原生交互限制。

`show_instance` 切换到指定运行实例，不刷新或重建网页。`read_manual` 读取随应用提供的说明书，`cdp_command` 使用内部 CDP；不需要用户另开外部控制端口。CDP 工具只开放列出的页面与输入命令，不支持任意协议调用。

不支持任意 Windows 桌面控制、任意 JavaScript 执行、密码或文件输入框填写；不承诺所有网站或扩展兼容。点击成功不等于业务完成，应再次读取结果。

## 网页观察与操作

AI 通过三个工具操作网页：

| 工具 | 作用 |
| --- | --- |
| `observe` | 返回网址、标题、可操作元素列表和视口内正文。每个元素带编号（如 `e12`），并标出角色、名称、当前值和状态（禁用、已勾选、展开、焦点、视口外等）。覆盖主页面、同源和跨站 iframe 以及开放的 Shadow DOM；带 `cursor:pointer` 的自定义按钮也会列出。`full_text` 返回整页正文；提供商开启图片支持时 `screenshot` 可附截图。 |
| `act` | 按编号操作元素：`click`、`dblclick`、`hover`、`type`（默认先清空，`submit` 输入后回车）、`press`（Enter、Escape、Tab、方向键、`Control+a` 等）、`select`（原生下拉）、`scroll`、`check`/`uncheck`。执行后等待页面稳定，返回网址/标题变化、新增和消失的元素、对话框及新弹出窗口。 |
| `dialog` | 处理网页的 alert / confirm / prompt 对话框。 |

实现要点：

- 点击和输入使用浏览器真实输入事件（网页看到的 `isTrusted` 为 true）。操作前把元素滚动到可见位置，并检测是否被弹窗、遮罩等挡住；被挡住时不点击，会返回遮挡元素。
- 元素编号在同一页面内保持稳定；网页跳转后旧编号全部失效且不再复用，需要重新 `observe`。
- 子框架独立跳转后，旧编号也会失效；每次观察清理已移除元素的编号，避免长任务累积过期引用。被遮挡的输入框不能通过输入或按键工具绕过遮挡。
- 页面稳定的判断：加载结束、网络静默 500 毫秒、DOM 静默 300 毫秒，至少观察 500 毫秒（地址变化时 1 秒），最多等待 5 秒。
- 主页面的辅助脚本运行在独立的 isolated world，不向页面写入标记；子框架的辅助脚本只能运行在页面环境中，使用随机名称。
- 实例使用固定视口并被缩放显示（或处于宫格）时，跨站 iframe 内的点击会改为脚本点击，并在结果中注明（Chromium 对缩放视口中跨进程框架的输入命中测试不准确）。
- 截图：JPEG，宽度不超过 1280 像素，作为不可信网页内容发给模型；请求中只保留最新一张，截图不写入会话记录。
- 密码框和文件上传框会出现在列表中，但不能操作。所有 `act` / `dialog` 操作遵循权限模式：仅可查看时禁止；逐项确认时确认卡片显示目标元素。
- 弹出窗口（网页用 `window.open` 打开的独立窗口）会列在 `observe` 结果的 `popups` 中，用 `tab` 参数（1～4）观察和操作。

旧的 `read_page`、`click`、`fill` 工具仍可执行（兼容历史会话），但不再提供给模型。

验证命令：`npm.cmd run test:ai-browser` 检查真实 Electron 中的页面观察、输入、框架、对话框、截图和设置保存；`node scripts/launch-electron.cjs tests/ai-stop-electron.cjs` 检查无进展停止、轮数上限及失败收尾；`node tests/ai-memory-runner.cjs` 检查跨进程记忆恢复。测试使用隔离数据与本机协议夹具，验证宿主执行链路，不代表所有第三方模型的推理或所有网站都已验证。

任务执行轮数默认不限，可在「设置 → 最多执行轮数」填写上限（1～1000，留空或 0 为不限，对所有提供商生效；任务开始时确定，执行中修改从下一个任务生效）。不限轮数时由以下机制收尾：重复结果或空读取达到保护阈值、同一操作与结果完全相同累计 20 次（原地循环）时停止工具执行，并给出已验证结果、未完成部分和下一步；单个任务的消息过大时，较早的工具结果会被替换为简短占位（保留最近 8 条完整结果），避免超出模型上下文。轮数不限意味着费用由任务长度决定，可随时点「停止」。最终说明失败或超过 20 秒时，由千面提供停止说明。主动点击「停止」会取消请求及待确认操作，已执行动作不会自动撤销。

## AI 随机创建实例的工具约定

用户要求随机环境与随机代理时，调用：

```json
{"action":"create","params":{"name":"实例名称","random":true,"start":false}}
```

用户要求打开时才设 `start:true`，可用 `sourceId` 限定已导入节点源。

1. 从可用候选中随机取样，最多尝试 5 个不同节点。没有节点时明确失败，不以直连代替。
2. 实测连通性，通过节点获取出口 IP、国家和 IANA 时区。旧缓存和节点名称不能替代实测。
3. 使用内置方案随机生成环境，语言按实测国家的默认语言、时区按实测结果匹配。
4. 全部候选失败、不完整或配置发生变化时，不创建未经验证的直连替代实例。
5. 检查返回的 `created`、`verified`、`started`、`configurationError`、`startError`。部分失败时先核对返回的实例 ID，不能盲目重建。
6. 随机节点不保证独享或全新 IP，检测通过不保证所有网站永远可访问。

只有明确要求原生、自定义环境或直连时才使用普通 `create`。随机创建成功的新实例加入当前任务范围。

## 本机数据

密钥保存在实际应用数据目录的 `ai-settings.json`；会话保存在 `ai-conversation.json`，使用系统加密与原子写入。系统加密不可用时不降级为明文。跨机器或 Windows 账号迁移可能无法解密。

旧单会话迁移前保留 `ai-conversation.json.pre-sessions.bak` 密文备份，之后的会话变化不会同步到该备份。删除会话移除当前记录，不自动删除迁移备份。恢复备份前请退出应用并另存当前文件；恢复旧备份不会包含之后新增的会话。

保存失败会显示记忆存储异常；读取或解密失败时保留原文件并阻止覆盖，不会因点击新任务而删除损坏文件。不要公开分享这些数据文件。
