# 内置 AI 助手

适用范围：当前源码工作区；安装包能力以对应发布版本为准。

## DSH 执行引擎与日常操作（v0.2.20）

内置助手使用 DeepSeek 官方开源 **DeepSeek Harness（DSH）** 的 AgentLoop、工具注册、Session 和插件上下文，固定版本 `0.2.1-rc.2`。它决定模型请求与工具执行的顺序；千面提供模型接口、网页和实例工具、权限检查、流式界面及系统加密持久化。无需安装 DSH CLI、另开终端或额外服务，也不要求使用 DeepSeek 模型；原有兼容 Chat Completions 的提供商继续可选。

原有提供商、密钥、会话和任务计划继续读取。每个会话对应一个长期保留的 DSH Session：每次任务都恢复（`ctx.agents.resume`）同一个 Session 再追加一轮，整段对话的历史、中断收尾、长工具结果精简和压缩都由 DSH 完成。Session 记录通过 DSH 官方持久化接口（`dsh-session-persistence`）写入千面的系统加密存储，不写明文日志。面板显示引擎版本、执行轮数和当前工具，工具结果默认折叠，消息可复制。

执行期间仍可输入，选择发送方式：

- **接着做**（默认）：进入当前会话待办，当前任务成功结束后依次执行，沿用该任务当时的实例范围和权限；最多 8 条。队列中的图片会加密保存。
- **立即补充**：通过官方 DSH `steer` 投递到下一步，不打断已经开始的操作，也不撤销其结果；实例范围、权限和模型继续固定。模型正在回复时，补充会在该次请求结束后的下一步送入。
- **停止、失败或计划未完成**：暂停后续待办。可以移除单条待办，或在检查实例范围和权限后点「继续待办」。停止不是回滚。
- **重启恢复**：恢复待办文字、图片和历史，但不自动执行，不继承完全权限；选择本次权限后手动继续。
- **继续处理**：停止或失败后可发送一条检查当前状态、继续未完成目标的消息，不盲目重放上次动作。

同时只运行一个会话。查看其他历史会话不打断执行；「返回运行会话」回到当前任务。输入草稿按会话分别保留在本次运行中；阅读旧消息时不会被强制滚到底部，可点「回到最新消息」。

迁移仅替换 Agent 执行层；DSH CLI 的任意系统命令、文件写入和其他插件并未默认开放。可用操作以本手册和宿主工具实际支持为准，DSH 不扩大原有权限。

验证：`npm.cmd run test:ai-dsh` 覆盖实际 DSH、真实 Electron 界面、追加/排队、异常停止及独立进程恢复；`test:ai-browser` 覆盖网页操作与截图；`test:ai-capabilities` 覆盖脚本执行、真实网络响应、实际文件上传与密码输入；`test:ai-memory`、`test:ai-sessions`、`test:ai-recovery`、`test:ai-stop` 检查各自链路。常规测试使用隔离的本机协议服务。可显式执行 `npm.cmd run test:ai-live -- --settings=<已有加密配置的绝对路径>` 调用实际模型，验证隔离本机网页上的一次真实点击，可能产生模型服务费用；凭据只读入内存，不复制到测试配置或输出。

## 对话显示（当前源码）

对话区参照 DSH 官方界面的结构显示：

- **回复按 Markdown 渲染**：标题、粗体、列表、任务清单、表格、代码块（带「复制」）和链接。解析使用与 DSH 官方界面相同的 micromark / mdast 管线，包括中文标点旁的粗体规则。网页内容和模型回复都按不可信内容处理：原始 HTML 只显示为文字，`javascript:` 等链接不可点击。
- **链接在实例里打开**：点击回复中的 http(s) 链接，会在当前运行的实例（或所选实例）中新开网页标签，沿用该实例的代理、环境和登录状态；控制界面本身不访问外部网址，回复里的图片也只显示为链接，不加载。
- **工具调用合并显示**：连续的工具调用合成一组，默认折叠，标题如「执行了 3 步 · 观察网页、操作网页」，失败步骤单独标出。每步显示目标实例、参数摘要和结果摘要，展开可看完整返回。输入框中键入的文字、对话框回答和网址中的查询参数不会出现在摘要里，也不会写入会话记录。
- **流式更新更平滑**：执行中约每 0.25 秒刷新一次，空闲时约 0.9 秒；只更新变化的消息和段落，已展开的步骤、选中的文字和滚动位置保持不变。已完成的任务计划自动折叠成一行进度。
- **输入区**：执行中「接着做 / 立即补充」显示在模型旁；选择「完全权限」时以醒目颜色提示。未配置模型时空白页提供「配置模型」入口，配置后提供示例任务。

验证：`npm.cmd run test:ai-panel`（解析与摘要单元测试，以及真实 Electron 中的渲染、安全、链接、工具分组和增量更新）。

## 追问、上下文用量与自动压缩（当前源码）

以下能力直接使用 DSH 官方后端插件（同为 `0.2.1-rc.2`），由千面接上自己的界面、模型接口和加密存储：

- **AI 可以向你提问**（`tool-ask-user` + `user-questions`）：需要你做选择、确认目标或补充信息时，AI 调用 `ask_user_question`，输入框上方出现提问卡片：每个问题可带标题、2～4 个选项（推荐项在前）、选项说明，可多选，也可在「其他回答」里直接输入。点「提交回答」后任务从原处继续；「暂不回答」会告诉 AI 你没有回答，由它按已有信息判断。等待回答时点「停止」会取消提问，不再发出模型请求。提问不能代替操作确认：网页和实例操作仍按「仅可查看 / 逐项确认 / 完全权限」执行。
- **上下文用量**（`token-meter`）：模型名称旁的小圆环显示当前上下文占用百分比，悬停可看已用 / 上限 tokens，以及本次任务的请求次数、输入（含缓存命中）和输出。千面在请求中附带 `stream_options.include_usage` 获取模型返回的真实用量；服务不支持该参数时自动去掉重发一次，本次运行内不再携带。没有返回用量时按 DSH 的估算显示并标注「估算」。
- **自动压缩**（`compaction-basic` + `tool-result-pruner`）：会话接近上下文上限时，先把较早的超长工具结果保留首尾精简，仍不够再把较早的对话整理为一份结构化摘要（目标、授权范围、实例与网页、已验证操作、失败与修正、未完成、下一步），任务继续执行。整段会话是同一个 DSH Session，所以压缩覆盖之前所有任务，摘要会随后续压缩合并，不会每个新任务都从头附上旧记录。触发、范围选择和替换由 DSH 完成；摘要请求由千面发送，使用当前模型、不带工具、按不可信资料处理网页内容。对话中会出现一条系统提示说明压缩了多少条记录。模型服务报告「上下文超出上限」时，DSH 会先压缩再重试一次。
- **上下文窗口设置**：「设置 → 上下文窗口（tokens）」按提供商填写，留空时按模型名称自动估计（名称含 `32k` 等按其数值；Gemini、GPT-4.1、DeepSeek V4 系列约 1M；GPT-5 约 400K；Claude 约 200K；其他 128K）。它决定圆环的上限和自动压缩的触发点（约为窗口的 80%；窗口小于约 24K 时还要再留出 4096 tokens 余量，比例更低）。自动估计偏保守，模型实际窗口更大时手动填写，压缩次数会明显减少。

千面不再自己压缩或精简会话记忆，旧版的「较早任务工具结果首尾精简」和「任务开始前记忆摘要」已移除。最近一次上下文用量随会话加密保存。

验证：`npm.cmd run test:ai-plugins`（用量映射、`stream_options` 降级、上下文超限识别、提问卡片与压缩记录的单元测试，以及真实 Electron 中的用量圆环、提问卡片的校验 / 回答 / 跳过 / 停止，和 24K 窗口下的自动压缩）；`test:ai-memory`（16K 窗口下跨任务压缩、重启后继续同一 Session、强制退出后的中断收尾）。

## 开始使用

点击顶部「AI」展开右侧面板。面板标题栏右侧依次是「新任务」「会话记录」「设置」「收起」四个图标按钮（悬停显示名称）。进入「设置」填写兼容 Chat Completions 的接口地址、模型和密钥；每次打开设置都会载入正在使用的提供商，列表中标有「使用中」和「编辑中」。可点击「一键获取模型」，也可手填模型名称。支持多个提供商，输入区可切换模型；任务执行中不能更换模型。默认配置为空，未配置不会发送请求。

每个提供商可勾选「模型支持图片」。勾选后 AI 观察网页时可以按需附带页面截图；未勾选时不会发送截图。

接口通常以 `/v1` 结尾。支持 HTTPS 和本机 HTTP；不接受地址内嵌凭据，不跟随重定向。模型请求走应用本机网络，不跟随浏览实例代理。调用费用由所选服务决定。

## 会话与记忆

- 「会话」查看历史，点击会话标题切换；支持改名和删除确认。
- 「新任务」另开会话，保留旧聊天。最多保存 200 个会话，不自动删除历史。
- 每个会话是一个独立的 DSH Session，保存全部消息、工具结果和压缩摘要，应用重启后从原处继续。你附的图片随消息保留最近 4 条用于后续请求，网页截图只在当次任务内发送、不保存。未发送草稿只在本次应用运行期间保留。
- 同一会话的历史不按实例范围拆分：换了授权实例后，模型仍能看到之前的对话，但每次任务只能操作本次授权的实例，越权调用会被工具拒绝。
- 切换会话不打断任务；同时只允许一个任务执行。返回运行中的会话可以审批或停止，运行中不能删除。
- 历史较长时由 DSH 自动压缩（见上文）；摘要可能丢失细节。界面最多显示最近 100 条记录。
- 任务被停止、失败或因关闭应用中断时，下一次任务开始时会先告诉模型上一轮的结果，要求它先核对状态、不要自动重复；未完成的工具调用由 DSH 标记为「结果未知」。
- 重启只恢复历史，不自动继续任务或恢复旧的完全权限。旧版单会话自动保留为「原有会话」。

## 任务计划与进度

复杂任务可由 AI 调用 `update_plan` 列出步骤；面板显示可折叠的「任务计划」、当前步骤与完成数量。支持待进行、进行中、已完成和受阻状态，最多 20 步，同时最多一步进行中。`read_plan` 读取当前计划；简单任务不要求先列计划。

计划随各自会话加密保存，切换会话和重启后恢复。继续同一会话时，最新计划会进入模型上下文，不依赖它从旧聊天里猜进度；点击「新任务」新建空会话，旧计划仍在原会话中。恢复历史不自动重放操作，也不继承旧的完全权限。

步骤由 AI 根据实际结果更新，计划状态不代替工具验证。本轮新建或重新核对的计划仍有待进行步骤时，宿主会继续追加收尾检查，让引擎完成已授权任务或说明真实阻碍；不再因两次提醒就强制暂停，也不会自动勾完。受阻步骤可保留为「已回复（计划未完成）」。用户停止和轮数上限仍立即有效。

后续消息、会话恢复和重启不把旧计划自动当作当前任务。界面将其折叠显示为「历史计划 · 未核对」，保留原步骤和时间；点击「继续旧任务」后，AI 先核对当前实例、权限与实际执行结果。问候和新问题不自动恢复旧操作，也不因旧计划未完成把这次回复判为任务失败。实例数量与状态以本轮清单和最新工具查询为准，不能从历史标题推断。只读模式也可整理计划，但不能因此执行实例或网页修改。

## 模型请求失败与重试

- HTTP 408、429、500、502、503、504，以及暂时连接中断，在尚未输出回复正文时最多尝试 3 次（含首次请求）。默认等待 1 秒、2 秒；服务给出 `Retry-After` 时按指定时间等待。等待超过 30 秒则停止并告知，不提前硬打；单次模型调用连同重试最多 90 秒。
- 面板显示重试次数和等待倒计时。「停止」可以取消正在等待或发送的请求，不会在后台继续重试。
- 只重试尚未完成的模型请求，保留既有工具结果，不重放已执行的点击、输入、创建或删除。已经输出部分正文后流中断，不自动重新生成，避免重复回复；未完整接收的工具调用不执行。
- HTTP 400、401、403 等配置或授权错误不盲目重试；响应格式错误也直接说明。服务错误正文不显示给用户，避免把上游敏感内容带入记录。
- 重试耗尽、空答复或其他请求失败时，提供明确的本地助手答复，说明未完成及下一步，并保存到会话，不再只留一条系统错误。

运行 `npm.cmd run test:ai-recovery` 可检查请求恢复、任务计划及真实界面链路。该测试使用隔离 Electron 数据与本机协议服务，不读取用户实例或调用付费模型。

## 发送与权限

Enter 发送，Shift+Enter 换行。可粘贴或选择 PNG、JPEG、WebP 图片，每条最多 4 张、单张不超过 5MB；图片理解取决于模型能力。正文支持流式显示。

选择单个或全部实例后发送，任务执行期间授权范围固定。三种权限：

| 模式 | 行为 |
| --- | --- |
| 仅可查看 | 可查询状态、读取网页，禁止修改 |
| 逐项确认 | 修改前显示对象、参数，确认后执行 |
| 完全权限 | 对本次授权范围内支持的操作直接执行，不逐项询问 |

网页内容、图片和会话上下文会发送给选中的模型服务。完全权限直接执行所选范围内的管理和网页工具；CDP 不再使用能力白名单。实例范围和用户选择的权限模式继续生效。切换提供商后的请求会发送当前会话上下文。

## 能力与边界

支持实例查询、创建、启停、改名、代理分配、环境配置，以及授权实例中的网页观察与操作（见下节）、导航、前进后退和刷新。管理工具复用千面的已有功能，扩展、备份和文件选择仍受原有权限与原生交互限制。

`show_instance` 切换到指定运行实例，不刷新或重建网页。`read_manual` 读取随应用提供的说明书，`cdp_command` 使用内部 CDP；不需要用户另开外部控制端口。支持 Chromium 实际提供的全部 CDP 命令，包括 Runtime.evaluate、Network、DOM、Input，以及可选 sessionId 的子 target 命令。

网页脚本执行、密码输入和本机文件上传已经可用；系统桌面控制仍不属于网页工具。不承诺所有网站或扩展兼容。点击成功不等于业务完成，应再次读取结果。

## 网页观察与操作

AI 通过以下工具操作网页：

| 工具 | 作用 |
| --- | --- |
| `observe` | 返回网址、标题、可操作元素列表和视口内正文。每个元素带编号（如 `e12`），并标出角色、名称、当前值和状态（禁用、已勾选、展开、焦点、视口外等）。覆盖主页面、同源和跨站 iframe 以及开放的 Shadow DOM；带 `cursor:pointer` 的自定义按钮也会列出。`full_text` 返回整页正文；提供商开启图片支持时 `screenshot` 可附截图。 |
| `act` | 按编号操作元素：`click`、`dblclick`、`hover`、`type`（默认先清空，`submit` 输入后回车）、`press`（Enter、Escape、Tab、方向键、`Control+a` 等）、`select`（原生下拉）、`scroll`、`check`/`uncheck`。执行后等待页面稳定，返回网址/标题变化、新增和消失的元素、对话框及新弹出窗口。 |
| `dialog` | 处理网页的 alert / confirm / prompt 对话框。 |
| `cdp_command` | 传 instanceId、method、params，执行实际 CDP。Runtime.evaluate 建议 returnByValue:true，异步操作加 awaitPromise:true。逐项确认模式执行前确认，完全权限直接执行。 |
| `network_log` | start 后触发网页请求，read 查看 URL、请求方法、响应状态、响应头与错误；按 after/cursor 分页，body 传 requestId 读取响应正文。clear 清空、stop 停止。只在内存保留最近500条，任务结束移除本工具监听，不调用 Network.disable，不占用 session.webRequest。 |
| `upload_file` | selector 指定真实 input[type=file]，files 传本机已有文件的绝对路径数组。可选 frameId 指定子框架。填写后应提交并核对网站实际收到文件。 |

实现要点：

- 点击和输入使用浏览器真实输入事件（网页看到的 `isTrusted` 为 true）。操作前把元素滚动到可见位置，并检测是否被弹窗、遮罩等挡住；被挡住时不点击，会返回遮挡元素。
- 元素编号在同一页面内保持稳定；网页跳转后旧编号全部失效且不再复用，需要重新 `observe`。
- 子框架独立跳转后，旧编号也会失效；每次观察清理已移除元素的编号，避免长任务累积过期引用。被遮挡的输入框不能通过输入或按键工具绕过遮挡。
- 页面稳定的判断：加载结束、网络静默 500 毫秒、DOM 静默 300 毫秒，至少观察 500 毫秒（地址变化时 1 秒），最多等待 5 秒。
- 主页面的辅助脚本运行在独立的 isolated world，不向页面写入标记；子框架的辅助脚本只能运行在页面环境中，使用随机名称。
- 正常浏览和宫格「放大查看」中网页按 1:1 显示，不缩放，跨站 iframe 内也使用真实鼠标点击。只有宫格小格子是缩小预览，在那里点击跨站 iframe 会改为脚本点击，并在结果中注明（Chromium 对缩放视口中跨进程框架的输入命中测试不准确）。
- 截图：JPEG，宽度不超过 1280 像素，作为不可信网页内容发给模型；请求中只保留最新一张，截图不写入会话记录。
- 密码框可用 act type 填写，观察和操作结果不回显密码；文件框使用 upload_file。所有 `act` / `dialog` 操作遵循权限模式：仅可查看时禁止；逐项确认时确认卡片显示目标元素。
- 弹出窗口（网页用 `window.open` 打开的独立窗口）会列在 `observe` 结果的 `popups` 中，用 `tab` 参数（1～4）观察和操作。

旧的 `read_page`、`click`、`fill` 工具仍可执行（兼容历史会话），但不再提供给模型。

验证命令：`npm.cmd run test:ai-browser` 检查真实 Electron 中的页面观察、输入、框架、对话框、截图和设置保存；`node scripts/launch-electron.cjs tests/ai-stop-electron.cjs` 检查持续轮询、手动停止、用户设置的轮数上限及失败收尾；`node tests/ai-memory-runner.cjs` 检查跨进程记忆恢复。测试使用隔离数据与本机协议夹具，验证宿主执行链路，不代表所有第三方模型的推理或所有网站都已验证。

任务执行轮数默认不限，可在「设置 → 最多执行轮数」填写上限（1～1000，留空或 0 为不限，对所有提供商生效；任务开始时确定，执行中修改从下一个任务生效）。不限轮数时不因重复读取、连续空结果、工具错误或重复20次而自动中止，允许模型纠正、轮询和继续任务。只按用户设置的轮数上限、手动停止、实际模型请求失败或模型完成结果收尾；单个任务的消息过大时，较早的工具结果会被替换为简短占位（保留最近 8 条完整结果），避免超出模型上下文。轮数不限意味着费用由任务长度决定，可随时点「停止」。最终说明失败或超过 20 秒时，由千面提供停止说明。主动点击「停止」会取消请求及待确认操作，已执行动作不会自动撤销。

## AI 随机创建实例的工具约定

用户要求随机环境与随机代理时，调用：

```json
{"action":"create","params":{"name":"实例名称","random":true,"start":false}}
```

用户要求打开时才设 `start:true`，可用 `sourceId` 限定已导入节点源。

1. 从未被任何实例分配的节点配置中随机取样，最多尝试 5 个不同配置；停止实例也算已分配，同配置跨订阅、改名后仍去重。不按延迟排序；未检测的候选必须先实测通过。没有候选时明确失败，不复用已分配节点或以直连代替。排队后、检测后及写入前复查分配和源版本。
2. 实测连通性，通过节点获取出口 IP、国家和 IANA 时区。旧缓存和节点名称不能替代实测。
   成功与失败均保存到对应节点的检测记录，供普通和批量随机选择使用。新的连通失败会替换旧可用状态；出口地区查询失败单独记录，不覆盖已成功的连通性。取消及源配置已变化的结果不会写入新的失败记录。
3. 使用内置方案随机生成环境，语言按实测国家的默认语言、时区按实测结果匹配。
4. 全部候选失败、不完整或配置发生变化时，不创建未经验证的直连替代实例。
5. 检查返回的 `created`、`verified`、`started`、`configurationError`、`startError`。部分失败时先核对返回的实例 ID，不能盲目重建。
6. 随机节点不保证独享或全新 IP，检测通过不保证所有网站永远可访问。

只有明确要求原生、自定义环境或直连时才使用普通 `create`。随机创建成功的新实例加入当前任务范围。

## 本机数据

密钥保存在实际应用数据目录的 `ai-settings.json`；会话列表、界面记录、计划和待办保存在 `ai-conversation.json`，使用系统加密与原子写入。每个会话的 DSH Session 保存在 `ai-dsh/facet-<编号>.log`：只追加写入，每行是一段系统加密的记录，写入后同步落盘；进程中途退出留下的半行会在下次写入前截掉，完整行解密失败则拒绝打开该会话并保留原文件。系统加密不可用时不降级为明文。跨机器或 Windows 账号迁移可能无法解密。删除会话时同时删除对应的 Session 文件。

旧单会话迁移前保留 `ai-conversation.json.pre-sessions.bak` 密文备份，之后的会话变化不会同步到该备份。从旧版记忆格式升级时另存一份 `ai-conversation.json.pre-dsh.bak`；旧会话的消息和摘要在该会话下一次任务开始时整理成一条「之前的对话（迁移自旧版本）」交给模型，此后作为 DSH 历史的一部分，旧图片不迁移。删除会话移除当前记录，不自动删除迁移备份。恢复备份前请退出应用并另存当前文件；恢复旧备份不会包含之后新增的会话。

保存失败会显示记忆存储异常；读取或解密失败时保留原文件并阻止覆盖，不会因点击新任务而删除损坏文件。不要公开分享这些数据文件。
