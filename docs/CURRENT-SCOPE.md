# 千面 Facet 当前功能范围

## v0.2.20 Agent 候选构建

内置助手已接入官方 DSH 0.2.1-rc.2 执行引擎，沿用千面原有实例/网页工具、模型接口和加密会话。新增执行中下一步补充、会话待办、暂停后手动继续及运行状态；面板按 DSH 交互显示 Markdown 回复和分组工具步骤，并复用 DSH 的提问（ask_user_question）、上下文计量和任务内压缩插件。不完整的扩展文件夹在导入时拒绝。无需额外 CLI 或常驻服务；未默认开放任意系统命令或文件写入。详见 [AI 手册](AI-AGENT.md) 与 [本版说明](releases/v0.2.20.md)。本地候选构建不等于 GitHub 已发布。

更新：2026-10-21；适用版本 v0.2.18 发布候选。[项目手册](PROJECT.md)、[文档索引](README.md)、[早期范围记录](SCOPE.md)。

## 已接入生产流程

- WebContentsView 真实浏览，每实例独立持久 Session、网站登录和存储；直连/代理明确选择。
- 实例单项与批量创建、启停、删除、备注、随应用启动；环境草稿、随机、保存与环境重置。
- 每个代理实例独立 Mihomo 进程与回环端口，Windows 进程保护/租约恢复；失败不静默切网页直连。千面本身不开系统 TUN、不修改宿主系统代理。
- 最多 30 个全局源：订阅、Clash/Mihomo YAML/JSON、常见单节点、编辑、更新、删除排除及恢复。明确分配才更新实例节点副本。
- 检测默认并发 3，可调 1–16；每任务最多 100 个节点；延迟、出口 IP、语言时区、手动单节点约 5 MB 测速，不回退目标网站直连。
- 语言、时区、UA/平台、视口/DPR、CPU、媒体偏好、定位和参考硬件/图形/音频/布局覆盖，固定种子；不等于物理硬件仿真。
- 解压目录或 ZIP 扩展导入、权限确认、实例绑定、面板/设置、更新并重启、确认停止受影响实例后移除；常用标签/框架/下载/数据/侧栏接口及实例内 debugger 兼容，具体边界见扩展专题。
- 扩展设备库按种子组合 GPU、屏幕/DPR 与硬件；普通随机保护浏览尺寸，旧实例不自动重新随机。
- 实时/省资源宫格、放大、音量/静音、主题、快捷网站、检测菜单、统一节点/IP 收藏。
- 环境重置以新 ID、新分区和随机环境重建，按实测出口匹配语言与时区；查询失败保留旧实例。保留名称、代理及扩展启用列表，清除旧登录和扩展数据，备注、自启动等恢复默认，支持批量；普通随机只修改草稿。
- 内置 AI 支持自选模型、图片、流式回复、多会话与持久上下文，按权限操作实例和网页；相关内容发送给用户配置的模型服务。
- 网页诊断通过 CDP 采集，修复诊断监听对扩展 DNR 执行的影响；按 manifest 默认值初始化静态规则集，保留扩展自身的启用选择。
- 实例内 F12 面板和拖动分隔条；本机 API + 单应用 CDP，默认关闭，回环访问。
- `.facetbackup` 导入导出、校验后可选删除、多文件导入、重新选择网络和异常恢复。
- Windows x64 安装包及 GitHub Releases 更新：启动及约每 30 分钟检查，同版一次提醒，下载安装由用户确认。
- 操作记录、跨重启应用/内核输出、网络失败阶段与详细诊断包；有明确采集上限，见 [日志说明](DIAGNOSTICS.md)。

## 待做或不提供

- CRX3 直装、商店安装、完整 Chrome 扩展 API。
- 定时订阅更新、运行中自动切换节点/网卡、保证最佳线路。
- 千面提供代理节点、系统 VPN/TUN、完整硬件仿真、完全匿名或不可检测保证。
- 外部网站账号注册/授权绕过等业务流程不属于应用自带能力。

节点 DNS 仅处理连接代理服务器，不控制订阅下载器，也不等于网页 DNS 设置。系统网络可能仍被宿主 TUN 接管；QUIC/WebRTC/预取防护不证明所有路径均无泄露。

普通网页无 Node/管理桥；IPC 接收控制窗口主 frame，API 需令牌，CDP 不使用同一 Bearer 校验。权限默认拒绝，剪贴板规范化写入、定位和受限文件读取按实现例外处理；剪贴板读取仍拒绝。

实例数量不设总上限，资源和页面限制实际并发；源/检测/批量动作各有约束。数据只保存在实际本机目录；凭据、Cookie 和实例备份不得进入 Git。应用代码 MIT，Mihomo 随包提供 GPL-3.0 许可、对应源码与校验；安装包未签名。

当前范围由源码支持，旧历史验收不证明新增草稿完成，详见 [验证记录](VERIFICATION.md) 与 [交付状态](UX-DELIVERY-STATUS.md)。
