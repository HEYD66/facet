## 根因与处理

只读核对实际环境参数：主工作区固定视口1760×920、DPR1；实例“2”宽高均为0，随窗口自适应。未读取真实订阅或网页内容，未改写这两个实例的配置。

原代码经CDP设置固定布局视口，但没有将其等比缩放到WebContentsView可用区域。较大虚拟页面会超出较小原生视图，固定定位在右侧/底部的控件被裁掉。修复把呈现缩放与DPR分离：固定视口保留网页布局宽高，按实际容器等比缩小、不放大；窗口resize和实例切换更新，连续更新合并处理。保持既有原生视图初始化流程。

设备预设和随机环境现在默认宽高0×0，自适应窗口，不再自动塞入“屏幕减160”的固定视口。模拟屏幕参数、DPR等其余选项保留。既有保存配置不迁移、不自动修改。固定视口可能显示较小文字；如不需要固定布局，在高级设置把视口宽高同时设0并保存，随后手动启动该实例。

## IP 收藏

- 入口在代理管理内容右上角，带收藏数量；左侧保留的是独立的“节点收藏”。
- 结果同行按钮显示“＋收藏 / ★ 已收藏”，再次点击取消；同IP多个节点的按钮同步。
- 持久保存、IPv4/IPv6规范化去重、同IP重复收藏幂等、不覆盖已编辑备注；保存中禁止重复点击，失败不虚报成功。
- 独立管理对话框：手动添加、按IP/备注搜索、编辑备注、单条/批量复制、选择筛选结果、清空选择、单条/批量确认删除。
- 筛选不会暗中清除已选隐藏项，选择计数明确提醒；删除只针对确认的ID。复制每行一个IP。
- 关闭对话框不丢节点筛选/订阅输入；IP编辑草稿在本次应用内保留，退出后不保留。错误会保留输入。
- 收藏的是地址备忘，不是可直接连接的代理，不影响节点副本、实例配置或运行状态。

## 回归发现与修正

全量回归额外发现：DPR输入框step=0.1会让预设的1.25被HTML原生校验阻止保存，表现为随机后偶发无法提交。已允许任意小数，仍由后端限制为0或1–3；六种预设的HTML原生有效性逐一验证，Windows真实保存用例固定覆盖1.25。没有以跳过断言掩盖失败。
