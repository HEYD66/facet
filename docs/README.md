## 文档维护规则

- 当前行为由源码和实际验证支持；历史命令编号、测试数量和截图只证明当时版本。
- 专项文档的当前摘要优先于其下方历史记录；历史记录保持原意，不能把旧版阻塞视为当前状态。
- 新功能未接线或未验收时写“开发中”，禁止提前列入用户可用功能或发布说明。
- 更新代码时同步用户说明、API 字段、数据兼容性和验证边界。发布后更新版本入口。
- 项目路径、用户数据目录与端口按运行环境确定；令牌和真实订阅凭据不进入文档。
- 文档只描述当前日志覆盖；旧日志没有采集的 DNS/TLS/内核细节无法靠导出补回。
