# 核心功能接入边界

> 本文是早期接入范围与增量历史，非当前功能承诺。当前已经包含扩展、安装包、指纹覆盖、本机 API、迁移等能力；请先阅读 [当前功能范围](CURRENT-SCOPE.md) 和 [项目手册](PROJECT.md)。原记录保留，不用旧版“不纳入本轮”判断当前版本。

用户已授权从 UI 阶段进入真实后台，并明确：没有代理节点时也要能用本机 IP 直连创建和运行。

## 已实现

- WebContentsView 真实浏览，每实例 persist session，独立登录和存储。
- 明确的 direct/mihomo 网络模式。创建默认直连；代理模式出错不静默回退。
- 官方固定版本独立 Mihomo，按实例进程与回环端口；不扫描其他客户端，不修改系统代理，不开 TUN。
- Clash/Mihomo 订阅链接导入、手动更新和本地 YAML/JSON 节点导入；每实例节点选择，固定内部节点别名防止特殊名称破坏规则。
- 稳定的语言/区域/时区；原生 UA/平台/UA-CH；不注入未经验证的 Canvas/GPU 伪装。
- 配置持久化、按实例队列、生命周期日志、显式批量操作、退出清理。
- 受限 IPC：只有控制窗口主 frame 可以调用；外部网页无管理桥、无 Node、禁止任意协议导航。

## 不纳入本轮

通用扩展、自动化注册/抽卡、外部业务 API、订阅定时更新、安装器、完整设备指纹伪装。不会从旧包迁入未核对代码。

## 后续验收

实例创建和批量节点分配不设固定数量上限，实际可同时运行的数量取决于硬件与网页负载。实时宫格持续加载所有运行网页，滚动只移动原生画布；省资源模式由用户自行选择。真实节点出口、WebRTC/DNS 泄漏、系统休眠/强制关机异常、长期稳定性与高并发仍需验证。Windows 已接入进程保护组件；正常退出停止实例并保留资料。

## 所有权

千面 Facet 项目仓库为 https://github.com/HEYD66/facet 。应用代码、安装包及公开更新清单来自该仓库；用户实例和登录资料保存在本机，不能提交到仓库。

## 全局代理管理增量

全局最多 30 个订阅/本地源；独立更新、编辑、删除，节点搜索/100 条分页。首次迁移旧订阅与节点，实例保留独立配置副本。明确分配才将目标实例切为代理并停止等待手动启动；全局更新/删除不自动改动实例。
提供单/批量连通性与出口 IP/地区查询、手动单节点 5 MB 下载测速；使用 Cloudflare 与 ipwho.is，用户确认后才发起外部检测，串行、可取消，不复用实例会话、不直连回退。仍不提供定时订阅更新、自动切换节点、完整泄漏保证。

## 本轮管理能力扩展（替代前述串行检测/仅基础环境范围）

按订阅折叠、提示条目人工复核、变化数量、筛选排序；默认3路可调1–6路独立并发检测，单独下载测速；双收藏（节点引用和IP备忘）；最近1000条持久脱敏全局日志/导出/摘要；停止实例详情与节点副本同步状态。高级CDP环境字段范围见README，不提供底层硬件伪装保证，不随机扰动Canvas/GPU。
