# 日志采集与详细诊断

更新：2026-10-14；v0.2.13 待发布构建。反馈问题时，复现后点击「系统日志 → 导出详细诊断包」，发送生成的 JSON，并附出错时间和操作步骤。新版采集需重启千面生效，旧版没有记录的信息无法补回。

## 两个导出入口

| 按钮 | 实际内容 |
| --- | --- |
| 导出操作记录 | 最近最多 1000 条系统/实例操作记录；保留旧 `export-logs` 数组格式 |
| 导出详细诊断包 | `facet-diagnostics` v2 JSON：版本/系统、实例概要、操作记录、跨重启运行输出、网络阶段、节点检测历史、故障索引和采集限制 |

无需开启外部 API 或 CDP。导出取消不会生成文件；写入失败显示失败。若输出或网络记录读写受限，导出结果会附 warning，界面也提示部分记录受限。

## 能看到什么

- 订阅：DNS 结果及公网/Fake-IP 分类、通过公网校验的候选地址列表、逐地址 TCP 尝试/失败/超时、TCP/TLS 阶段、证书错误、HTTP 状态、重定向、接收/解压字节、解析和保存结果、相对阶段耗时及总耗时。全部连接失败时保留聚合错误中的逐地址错误码；单个地址失败后其他地址成功不算整次下载失败。
- 节点：当前 DNS/路由准备结果、已有回退行为、内核 PID/端口/生命周期及脱敏输出；检测目标、响应、错误码和已保存的统计历史。
- 浏览器：页面/框架加载失败，HTTP(S) 请求失败与 4xx/5xx 状态、资源类型、关联实例；异常渲染进程退出。
- 应用：操作记录、标准输出/错误、控制界面的警告及错误。运行 ID、实例 ID、任务 ID 用于关联，不包含访问令牌。

先看 `summary.issues` 的失败阶段和错误码，再按 ID 查 `network.rows`、`debug.rows`。`diagnostics.history` 是节点统计、最近结果和每种检测最多 10 次历史，并非所有探测的无限存档。内核文本提取的分类码不等于操作系统原始错误码；错误来自哪类事件由 operation/stage 标明。连接重置本身不能证明服务器封禁或 TUN 配置错误。

## 留存、缺失与隐私边界

| 记录 | 上限与位置 |
| --- | --- |
| 操作 | 数据目录 `global-events.json`，最近 1000 条 |
| 应用/内核输出 | `runtime-output.json`，最近 5000 行；界面显示最近 1000 行；单行最多 700 字符 |
| 网络任务 | `network-trace.json`，最近 300 个任务，每任务最多 160 个阶段；文本字段最多 180 字符 |
| 节点历史导出 | 最近最多 1000 个节点统计，来自现有检测历史存储 |

输出与网络记录跨重启保存；未完成网络任务下次启动标为 interrupted。保留起止时间、dropped、stepsDropped、longLinesTruncated 和逐行 truncated 标记可判断删减。超长分片输出整段省略，防止凭据片段漏出。读入历史文件超过 12 MiB 或损坏时保留原文件、标明警告，仅内存采集。运行时合并写盘，正常退出和导出前刷盘；强制断电可能损失尚未落盘的最后一段。

记录必要域名、IP、端口与关联信息，不保存网址路径/查询、请求头、响应正文、订阅配置、Cookie、密码、实例备注和网页内容。普通网页 console 不采集。应用/内核文本会脱敏再写盘，导出再次脱敏；反馈前仍可检查域名/IP是否涉及不希望公开的网络信息。

Electron 网页事件不提供独立 DNS/TCP/TLS 阶段，只能提供失败事件或 HTTP 状态；完整阶段来自订阅下载器，内核输出作为关联证据。只记录 HTTP(S) 请求失败，成功网页浏览记录、所有协议抓包、崩溃转储、扩展完整控制台均不在范围内。无法承诺所有 bug 都能仅靠此包定位。页面请求失败的采集范围是千面已附加内部 CDP 的实例主页面、弹出窗口和扩展浏览窗口；跨站独立进程 iframe、Service Worker 与扩展后台发出的请求不在范围内。扩展主动拦截（`ERR_BLOCKED_BY_CLIENT`）、CORS 拒绝、预检请求和用户中止不计为失败。

## 维护与验证

入口：`runtime-output.cjs`、`network-trace.cjs`、`network-capture.cjs`、`diagnostic-bundle.cjs`。网络采集仅观察，不修改 DNS、代理、路由或请求。页面请求失败经各页面已有的内部 CDP（Network 域，响应缓冲上限 1 MB、单资源 256 KB）采集。**禁止在实例 Session 上注册任何 `session.webRequest` 监听（包括只读的 `onCompleted` / `onErrorOccurred`）**：只要存在监听，Electron 就绕过扩展请求代理，扩展 DNR 规则（拦截、跳转、改头）会全部静默失效；`tests/network-capture.test.cjs` 含源码守卫。扩展经调试器关闭 Network 或断开时，只停止向该扩展转发，诊断采集保持开启。停止实例和退出时移除本模块拥有的监听器。

执行 `npm.cmd run test:diagnostics`、`npm.cmd run test:diagnostics-electron`，以及项目要求的 check、test:control-api、git diff --check。真实测试使用临时用户目录和本机故障服务器，保存框由受控目标路径适配，生产采集、IPC 和写盘均实际运行。详见 [验证记录](VERIFICATION.md)。

修复前检查点 `0dba664`。回滚优先 revert 最终修复提交并重新构建；先正常退出并备份实际用户数据目录中的两个日志文件。不要删除实例或网络配置来回滚日志。旧程序不会拥有新版采集能力。
