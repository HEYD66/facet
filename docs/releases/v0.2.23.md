# 千面 Facet v0.2.23

本次新增网页内查找和右键菜单，并按界面审查整理了设置、代理管理、实例管理、新建实例和日志页面。

## 本次更新

- **网页内查找（#11）**：浏览页面按 Ctrl+F，地址栏下方出现查找栏，显示「第几个 / 共几个」。Enter、Shift+Enter 或箭头按钮跳到下一个 / 上一个，Esc 关闭并回到网页。只查当前网页标签；宫格缩略图里不提供查找。
- **网页右键菜单（#11）**：普通区域有后退、前进、重新加载、在此页查找和检查；链接可在新标签页打开或复制地址；输入框有撤销、剪切、复制、粘贴、全选；选中文字可复制或直接在此页查找。扩展添加的右键菜单项排在最后，不再另外弹出一个菜单。
- **节点 DNS 设置**：提示条只显示已经保存的设置，下拉框里改了没保存不会被当成「当前设置」；有未保存的修改时会标出，离开设置页前提醒保存。夜间主题下这条提示原来几乎看不清，现在可以正常阅读。
- **代理管理**：「代理运行方式」平时收成一行，显示当前模式和端口信息，点「更改」才展开两种模式的说明。节点列表因此上移，小屏幕上能多看到两三行节点。
- **实例管理**：顶部的数量统计并入状态筛选按钮，少占一行；各行的「配置 / 日志 / 更多」按钮对齐，不再因为有没有「日志」按钮而错位。
- **新建实例**：选择本机 IP 直连时，「按代理管理的地区设置时区和语言」会变灰并说明原因（这个选项只对节点生效）。
- **日志**：系统日志和实例运行日志里的 ERROR、WARN、INFO 用不同颜色显示，更容易找到报错。
- **键盘操作修复**：用快捷键或 Enter 切换网页标签后，键盘焦点会留在原来的标签上，不再丢失。

## 升级说明

- Windows x64。正常退出并重新启动千面后生效，保留已有实例、代理、登录资料、扩展及 AI 配置。
- 自己拦截 Ctrl+F 的网站（如部分在线文档）现在会打开千面的查找栏。
- 安装包未签名。

修复了一些旧 bug，新增了一些新 bug。如果你有遇到，欢迎[在此反馈](https://github.com/HEYD66/facet/issues)。
