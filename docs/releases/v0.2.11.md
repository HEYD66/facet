# 千面 Facet 0.2.11

本次更新开放节点 DNS 配置和本机外部控制，新增隐私检测入口，并改善浏览器 DNS 预解析防护。

## 更新内容

- **开放节点 DNS 与出站网络配置**：在「应用设置」选择系统 DNS、自动兼容、安全 DNS或严格模式，并选择跟随系统路由、自动物理网卡或指定网卡。默认使用系统 DNS 与系统路由，升级保留已有配置；支持重置为默认。
- **改善 DNS 失败处理**：自动兼容和安全 DNS 在 DoH 失败时回退系统 DNS，继续尝试连接并记录提示；严格模式失败时停止，不回退。保存设置不重启当前实例，下次启动或检测生效。
- **加强浏览器 DNS 预解析防护**：关闭网页 DNS 预取提示；实例词典下载延后到网络配置完成，代理实例通过自身代理下载。
- **新增本机 API 与统一 CDP 开关**：外部工具可管理实例、调用现有操作通道，并通过 CDP 控制运行网页。按实例 ID 对应页面 target，控制操作支持界面跟随。默认关闭，仅监听本机回环地址；开启 CDP 需重启应用。
- **附带 AI 接手说明**：复制连接信息时一并复制说明书入口，路径按实际运行或安装目录生成；安装包附带接手文档。
- **新增隐私检测菜单**：快捷网站栏点击「检测」，展开 ipip.la、IPLeak、BrowserLeaks DNS、DNSLeakTest、IPPure，在当前实例内打开，沿用该实例的网络与独立会话。支持日间、夜间主题，不增加工具栏高度。
- **清理重复快捷入口**：快捷栏中的旧 ipip.la 入口统一移入检测菜单，升级自动清理重复项，保留其他快捷网站。

## 使用说明

节点 DNS 设置仅控制节点服务器的域名解析，不等同于网页 DNS 防泄露，也不保证所有节点都能连接。严格模式不适合需要失败回退的场景。检测网站的 DNS 归属不能单独证明是否泄露或确定泄露来源。

下载 `Facet-Setup-0.2.11-x64.exe`。升级前正常退出千面，安装后保留原有实例配置、登录存储和扩展。安装包未签名，附带 SHA256 校验文件；现有安装版可通过软件更新检查、下载并确认安装。
