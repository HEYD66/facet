# 千面 Facet 0.2.16

## 新增内置 AI 助手

- 新增右侧 AI 面板，统一管理授权实例并操作实例网页。
- 支持兼容 Chat Completions 的模型服务、多提供商配置、一键获取模型和模型切换。
- 支持流式回复、图片输入、Enter 发送及 Shift+Enter 换行。
- 提供仅可查看、逐项确认、完全权限三种模式；完全权限下直接执行授权范围内支持的操作。
- 新增会话管理：新建、切换、改名和删除。新任务保留旧聊天，各会话独立保存上下文和图片，支持长对话压缩与重启恢复。
- 切换会话不打断正在执行的任务，同时只允许一个任务执行。
- AI 随机创建实例时，随机选择已导入节点，检测连通性并获取出口信息，匹配语言与时区；检测失败不以直连替代。
- 修复重复读取空页面后没有最终答复的问题；停止执行后提供总结，模型异常时给出本地说明。

## 实例与扩展体验

- 从实例管理启动实例后留在管理页面，方便连续启动多个实例。
- 扩展更新支持「更新并重启」，自动恢复本次受影响的运行实例；原本停止的实例保持停止。
- 重置环境改为新 ID、新存储分区和新随机环境重建，仅保留名称与代理相关配置，避免继续复用旧环境。

## 使用说明

- AI 接口、模型和密钥由用户自行配置，费用由所选服务决定；网页内容、图片和上下文会发送给该服务。
- 会话和密钥在本机加密保存。升级保留已有单会话；不会自动恢复中断任务或旧的完全权限。
- 重置环境会清除旧登录资料，实例 ID 会改变；外部脚本需要使用新 ID。
- 本次未修复扩展 DNR 规则不生效及部分本机地址经实例代理访问失败的问题，不宣称所有插件或网站完整兼容。
- Windows x64 安装包；复用现有内核。安装包仅包含审核过的使用说明，不附带私人开发记录、验收资料或未完成草稿。
