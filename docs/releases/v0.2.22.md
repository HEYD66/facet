# 千面 Facet v0.2.22

本次修复人机验证框点击不通过、宫格里的嵌入页面无法操作和 AI 过早压缩，并让随机环境的显卡、屏幕、音频等读数更接近真实 Chrome。

## 本次更新

- **人机验证框可以正常点击**：最大化窗口、固定视口大于窗口和宫格「放大查看」时，网页不再缩放显示，一律按 1:1 呈现，Cloudflare 等验证框点击后可以通过（#10）。窗口比模拟屏幕大时，网页居中显示，四周留空。宫格小格子仍是缩小预览，验证框需要放大后操作。
- **宫格小格子里的嵌入页面可以操作**：跨站 iframe（如 arena.ai 的 HTML 预览、嵌入的登录或支付组件）在小格子里也能接收点击和滚轮。
- **AI 会话不再频繁压缩**：每个会话的历史交给 DSH 持久保存和管理，长对话里新任务不会一开始就压缩。升级后旧会话在下一次任务时自动迁移，原文件另存为 `ai-conversation.json.pre-dsh.bak`。AI 在页面远距离滚动后点击嵌入页面也更准确。
- **随机环境更接近真实 Chrome**：
  - WebGPU 读到的显卡与 WebGL 的模拟显卡一致（之前是本机真实显卡），对已开启 WebGL 覆盖的旧实例同样生效。
  - 音频指纹按实例区分（之前所有实例相同）；窗口外尺寸不超过模拟屏幕。
  - 模拟像素比读数为精确值；默认 UA 不再带「千面Facet」字样。
- **新生成的环境**（新建、批量、重置、一键随机、选用预设）：
  - 显卡渲染器带设备 ID，格式与真实 Chrome 一致；内存最高报告 32 GB，按显卡档位搭配。
  - 屏幕可用高度按 Windows 11 任务栏计算；触摸点与本机一致。
  - 像素比与本机显示器一致，嵌入的验证框和主页面读到的值相同。
  - 屏幕不小于当前显示器；高端显卡不再配小屏，老显卡的线程数和屏幕更合理。
  - 一键随机旁新增「同时随机屏幕」，勾选后一并重新抽取屏幕和像素比。

## 升级说明

- Windows x64。正常退出并重新启动千面后生效，保留已有实例、代理、登录资料、扩展及 AI 配置。
- 已保存实例的环境不会自动重新随机。像素比与本机显示器不同的实例，嵌入的验证框里仍是本机值，环境页会提示；需要时勾选「同时随机屏幕」后一键随机并保存（会改变该实例的屏幕和像素比）。
- 这是现有 Electron 环境覆盖方案的改进，不代表已接入原生指纹内核。字体、请求头里的 UA 客户端提示、WebGPU 能力上限等仍是本机值，不保证通过所有网站的检测。
- 安装包未签名。
