# 千面 Facet v0.2.24

本次新增「获取免费节点」：没有订阅也能从公开列表里找到当前可用的节点，验证后直接导入代理管理。

## 本次更新

- **获取免费节点**：进入「代理管理 → 获取免费节点」，选择节点类型（公开 HTTP / SOCKS5 代理、加密协议节点）和要找到的数量（默认 30 个），点「开始获取」。千面从 45 个公开列表里每次抽取 16 个下载候选，逐个验证，可用的导入「免费节点」源。开发机上一次实测找 30 个用时约 24 秒，实际用时取决于网络和当时的节点质量。
- **先验证再导入**：每个候选节点都要通过内置 Mihomo 实际完成一次 HTTPS 请求并返回出口 IP 才算可用，同时测出延迟、出口国家、城市和时区。导入后的节点已带有连通性和出口 IP 记录，可以直接分配给实例，也可用于批量创建；新建实例时按这份记录设置语言和时区。
- **后台运行**：关闭弹窗后任务继续，入口按钮显示进度，结束时提示结果；可以随时停止，已经验证通过的节点照常保存。
- **追加而不是覆盖**：再次获取时原有免费节点和检测记录保留，节点库里已有的地址不会重复验证；也可以勾选「找到新节点后清空原有免费节点」。
- **排在最前**：「免费节点」源固定排在节点源列表和新建实例「初始网络出口」的第一位。
- **本机控制 API**：新增 `library-free-start`、`library-free-cancel`，进度和结果在 `snapshot` 的 `freeNodes` 中，说明见随包文档「本地控制 API 与 CDP」。

## 使用前请了解

- 免费节点由身份不明的第三方运营，存活时间短，速度和稳定性没有保证。公开 HTTP / SOCKS5 代理不加密，对方能看到并改动未加密的流量。**不要用免费节点登录重要账号。**
- 验证通过只代表当时可用。已导入的节点不会自动更新或自动清理，失效后需要自己检测并删除，再获取一批。
- 出口在中国大陆的节点不会被过滤；个别节点查不到时区时只记录国家，新建实例会提示在环境配置中确认。
- 从节点库删除节点不影响已经分配给实例的节点副本，实例会继续使用原节点，需要重新分配才会更换。
- 下载公开列表使用系统网络，需要能访问 jsDelivr 或 GitHub。
