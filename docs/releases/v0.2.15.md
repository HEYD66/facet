# 千面 Facet 0.2.15

## 内存与运行稳定性

- 修复实例停止、删除后网络监听引用未释放的问题，避免反复创建和删除实例时残留累积。
- 修复扩展弹窗关闭后仍保留已销毁页面引用的问题。
- 优化宫格缩略图：合并重复请求、限制同时截图数量，退出宫格后丢弃过期结果并清理缩略图缓存。
- 修正 Windows 内存统计，补计代理内核及进程保护组件，提供各类进程的占用明细。显示值为私有提交内存，不等同于物理内存驻留量。

## 环境重置

- 补齐已安装扩展的本地存储清理，包含停用扩展；保留扩展包及启用选择。
- 重置后校验 Cookie 是否清空，继续清理网页存储、缓存及导入 Cookie 恢复任务。
- 增加可跨应用重启保留的“重置未完成”记录：中途失败时提示部分数据可能已清除，并阻止实例启动；再次点击“重置环境”可继续完成。
- 重试沿用原定的新环境，保留代理与实例管理资料，不影响其他实例。
- 网站或扩展重新运行后可能生成新的访客 Cookie、默认配置；这不代表旧登录数据恢复。已清除的数据无法通过失败重试还原。

## 兼容性

- 补充指纹注入函数的 toString 兼容处理，改善函数名称、参数数量和调用行为的一致性；不承诺所有检测场景完全不可识别。

## 验证与说明

- 已验证重复启停、实例删除、扩展弹窗回收、重置后的浏览存储与扩展存储、故障重试及跨进程恢复。
- 已验证单个与批量重置界面，代理与其他实例数据保留。
- 完整扩展兼容回归中，声明式网络规则拦截测试仍有既有失败；修改前代码同样复现，未宣称全部扩展兼容。
- 本次发布为 Windows x64 安装包，复用现有内核。内存优化不承诺固定降幅，也不能据此认定所有高占用都是泄漏。
