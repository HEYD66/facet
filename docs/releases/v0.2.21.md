# 千面 Facet v0.2.21

本次优化浏览环境兼容性，并将新建网页标签默认页改为必应。

## 本次更新

- **随机环境组合优化**：生成 CPU 线程数时参考显卡档位，减少低端显卡搭配超高线程数等明显不合理的组合。已有实例不会因升级而自动重新随机。
- **Chrome 网页接口兼容**：补齐网页中的 `window.chrome.app`、`chrome.csi()` 和 `chrome.loadTimes()`，改善依赖这些接口的网站兼容性。
- **自定义 UA 信息修复**：Windows Chrome 自定义 UA 或旧版本 UA 不再直接清空 UA-CH 品牌列表，改为按 UA 中的版本生成对应的品牌与完整版本信息。
- **新标签页默认打开必应**：点击标签栏「+」、按 Ctrl+T、通过 API 或 AI 新建未指定网址的标签，以及关闭最后一个标签后补开的页面，均默认打开必应，并沿用该实例的代理和登录环境。显式指定 `about:blank` 仍可打开空白页；扩展未指定网址时的行为保持原样。

## 升级说明

- Windows x64。正常退出并重新启动千面后生效，保留已有实例、代理、登录资料、扩展及 AI 配置。
- 这是现有 Electron 环境覆盖方案的兼容性改进，不代表已接入原生指纹内核，也不保证通过所有网站的检测。
- 安装包未签名。新标签页需要通过实例当前网络访问必应；节点不可用时会显示加载失败。

修复了一些旧 bug，新增了一些新 bug。如果你有遇到，欢迎[在此反馈](https://github.com/HEYD66/facet/issues)。
