# 千面 Facet 0.2.12

本次更新新增环境重置，完善实例开发者工具与扩展调试兼容，并修复宫格放大、代理故障判断和环境表单刷新问题。

## 新增与改进

- 环境重置：在实例管理或环境配置中清除目标实例的 Cookie、缓存和网站存储，重新随机环境配置及种子；保留代理配置、实例名称和管理资料。支持批量重置，操作前会确认；环境配置入口位于“环境方案”行的“一键随机”之后。
- 实例开发者工具：支持 F12、工具栏按钮和本机 API 切换，在实例网页右侧显示；可拖动中间分隔条调整宽度，实例停止时自动关闭。
- 扩展调试兼容：适配使用 chrome.debugger 的检测扩展，按实例连接对应网页，不影响统一外部 CDP 入口。
- 升级弹窗：在个人声明下方增加 Star 支持提示，将“去点 Star”按钮移到提示同一行，以强调色突出显示；保留更新内容、项目地址和立即更新入口。

## 问题修复

- 修复环境重置后表单仍显示旧配置的问题，清理旧草稿和撤销状态，再读取已保存的新配置。
- 修复桌面硬件方案在重置后未正确应用的问题，桌面方案默认触摸点数为 0。
- 修复开发者工具出现独立空白窗口的问题，改为在千面窗口内展示。
- 修复宫格放大窗口遮挡其他窗口的问题；从放大查看切回浏览页面时保留原网页及输入状态。
- 调整代理故障判断，单个网站访问失败不再直接认定整个实例代理失效。

## 保留的功能

本版包含此前开放的节点 DNS 与出站网络配置、本机 API 与统一 CDP 开关、AI 接手说明和隐私检测菜单。节点 DNS 默认使用系统 DNS 与系统路由，升级保留已有设置；它只影响节点服务器域名解析，不等同于网页 DNS 防泄露。浏览器继续关闭网页 DNS 预取提示，并延后实例词典下载至网络配置完成。

## 安装说明

下载 `Facet-Setup-0.2.12-x64.exe`。升级前正常退出千面，安装后保留实例配置、登录存储和扩展。**环境重置会清除所选实例的浏览数据，无法通过普通撤销恢复，请确认后使用。**

安装包未签名，附带 SHA256 校验文件。现有安装版可通过软件更新检查、下载并确认安装。
