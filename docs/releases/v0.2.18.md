# 千面 Facet 0.2.18

本次主要完善 AI 网页操作、浏览环境在不同页面与 Worker 中的一致性，以及视口和扩展调试兼容性。

## 本次更新

- **AI 网页操作增强**：支持观察页面、定位元素、点击输入、选择、滚动及网页对话框，覆盖 iframe 和开放的 Shadow DOM；操作后返回页面变化与遮挡信息，减少重复盲操作。
- **AI 任务执行与恢复**：增加任务计划和进度；网络异常、限流及部分服务错误按规则重试，失败后提供明确答复；计划与会话持续保存，重启后可查看上次状态。
- **网页与 Worker 环境一致性**：补齐 Dedicated、Service、Shared Worker 和跨站 iframe 的环境初始化，修复部分上下文第一段脚本读到原生设备信息的问题。
- **外部自动化连接修复**：协调外部 CDP / Playwright 与内部环境初始化，支持多客户端、重连和 F12 共存；修复私有调试管道影响正常手动浏览状态的问题。
- **Canvas、音频与 API 兼容性**：完善 OffscreenCanvas 导出与固定种子一致性，保留参数转换、异常和调用时序；修复网页重写 JavaScript 辅助方法后引起的注入异常。
- **自适应视口修复**：修复新建或重置环境后，小尺寸模拟屏幕导致网页右侧、底部留黑边的问题；自适应页面等比铺满窗口，逻辑视口不超过模拟屏幕。兼容不同 DPR 与系统缩放，保留环境配置和页面状态，并同步修正 AI 点击坐标。
- **扩展启停自动恢复**：更改扩展启用范围后，自动恢复原先运行的受影响实例；停止的实例保持停止，无关实例不受影响。批量更改逐项反馈保存与恢复失败，扩展及网站已保存的数据保留。
- **检测入口补充**：检测菜单新增 Net.Coffee，方便自行检查网络与浏览环境。
- **运行时安全更新**：升级 Electron 至 44.9.3，代理核心使用固定的官方 Go 1.26.10 安全构建，拒绝受损证书链；核验并使用已修复的共享 Brotli 解码器，保留压缩与流式输出兼容性，并加强订阅/AI 的 TLS 主机名与连接复用防护。完整修复边界见[安全说明](../RUNTIME-SECURITY.md)。

## 使用说明

- Windows x64；升级保留已有数据，更新后需重启应用加载新版运行时。Mihomo 目前为固定 SHA256 与源码提交的官方预发行安全构建；Electron 内置 Node 仍为 24.22.0，已对应用实际网络入口加防护，尚不代表包含 Node 24.22.1 全部底层修复。
- 本版的环境一致性和兼容性修复不代表所有验证码、风控网站或第三方工具都兼容；第三方内核、自定义 UA 元数据、完整 GPU 能力与噪声算法仍存在实现差异。
- 已知显示限制：手动设置的固定视口仅缩小适配，较大窗口下可能在右侧或底部留白；本次铺满修复针对自适应模式。需要随窗口铺满时，可将高级环境设置中的视口宽、高都设为 0。
- AI 使用用户配置的模型服务；任务涉及的网页内容、图片和上下文可能发送给该服务。完全权限仅覆盖本次授权范围内的工具；敏感输入及文件选择等仍受宿主限制。
- 外部控制默认仅监听本机。连接信息和访问令牌请妥善保管，不要上传到反馈或公开仓库。
