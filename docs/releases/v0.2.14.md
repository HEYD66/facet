# 千面 Facet 0.2.14

修复整套随机环境可能导致网页文字、按钮明显缩小的问题。

## 视口修复

- 整套随机、新建/批量创建的随机环境和环境重置，默认使用宽、高为 0 的自适应视口；抽到高分辨率屏幕时，不再自动把实际浏览视口设为该屏幕尺寸。
- 保留随机屏幕、像素比与硬件配置；用户手动指定的固定视口仍保留。
- 普通“一键随机”继续保留当前浏览尺寸。已有实例如果保存过较大的固定视口，请将视口宽、高都改为 0，保存并重新启动实例，无需清除网站数据。

## 验证与范围

已验证自适应像素比 2、随机 4K 屏幕、手动固定 4K 视口的实际页面尺寸及嵌入框架鼠标点击，并通过环境保存、重启和重置回归。用户反馈的第三方验证码无法点击尚未复现，本次不宣称已解决该问题。

下载 `Facet-Setup-0.2.14-x64.exe`，正常退出千面后安装。升级保留已有实例、登录存储、代理和扩展；不会自动修改旧实例的视口设置。安装包未签名，附带 SHA256 校验文件。

修复了一些旧 bug，新增了一些新 bug。如果你有遇到，可以[在此反馈](https://github.com/HEYD66/facet/issues)。
