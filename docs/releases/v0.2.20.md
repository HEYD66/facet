# 千面 Facet v0.2.20
本次将内置 AI 的执行引擎接入 DeepSeek 官方开源 DSH，并按 DSH 的交互改造 AI 面板：回复按 Markdown 显示，AI 可以向你提问，显示上下文用量，长任务自动压缩上下文。
## 本次更新
- **接入官方 DSH**：使用官方 AgentLoop、工具注册、Session 和插件上下文驱动模型与工具；沿用千面的模型接口、实例控制、网页操作及权限边界。继续支持自选模型，无需安装额外 CLI 或启动其他服务。
- **回复更好读**：AI 回复按 Markdown 显示标题、列表、表格和带「复制」的代码块；回复里的链接在当前实例中新开网页标签打开，沿用实例的代理和登录。连续的工具调用合成一组可折叠的步骤，显示目标实例、参数和结果摘要；键入的文字、对话框回答和网址查询参数不会出现在摘要里。
- **AI 可以向你提问**：需要你做选择或补充信息时，AI 会在输入框上方弹出提问卡片，可单选、多选、填写其他回答或暂不回答；回答后任务从原处继续，停止任务会取消提问。网页和实例操作仍按你选的权限执行。
- **上下文用量与自动压缩**：模型旁的小圆环显示上下文占用，悬停可看用量和缓存命中。单个任务接近上限时，先精简较早的长工具结果，仍不够再把较早的对话整理成摘要继续执行；模型服务报告上下文超限时先压缩再重试。设置中可按提供商填写上下文窗口，留空按模型自动估计。
- **执行中继续输入**：默认「接着做」将消息加入待办；「立即补充」在下一步提供最新要求，不撤销已执行的动作。待办支持图片和移除，按会话独立保存。
- **停止后的控制更清楚**：停止、失败或计划未完成时暂停后续待办，提供「继续处理」「继续待办」入口。重启后恢复历史与待办，等待手动继续，不自动恢复旧的完全权限。
- **面板整理**：标题栏改为图标按钮；实例范围与模型改为轻量选择；确认卡片与提问卡片样式统一；打开设置时始终显示正在使用的提供商。
- **执行与恢复修复**：移除重复读取、空结果及工具错误触发的自动中止，允许持续轮询、修正与重试；连续截图只发最新画面，历史保留位置说明且不保存网页截图；退出时等待 Agent 停止并保存会话。
- **旧计划与当前任务分开**：历史计划折叠标记为未核对，问候不会恢复旧任务或沿用旧实例数量；当前已授权计划未完成时继续收尾检查直至完成或说明实际阻碍，支持继续旧任务。
- **网页控制能力补齐**：放开内部 CDP 命令，支持页面脚本、DOM 和网络操作；新增真实网络请求/响应观察与文件上传，密码框可输入且不回显。完全权限直接执行，保留实例范围、可选确认模式和手动停止。
- **扩展**：扩展中心可设置新建实例默认携带的扩展，普通、批量及 AI 创建保持一致。缺少脚本或图标等文件的扩展文件夹在导入时直接拒绝并列出缺少的文件；已导入的不完整扩展会标出问题，不能再启用到实例上，启动失败时提示写明扩展名和原因，不会先停下正在运行的实例。
- **宫格与菜单**：宫格中从未显示过的网页也能生成缩略图；收藏等菜单弹层的画面不再停在旧帧。
- **后台标签与日志**：修复重启、环境覆盖关闭及仅调整时区等路径下后台网页策略未完整恢复的问题；运行输出中重复的扩展加载警告只保留首条，避免挤掉其他记录。
## 升级说明
- Windows x64。正常退出并重新启动千面后生效；保留已有实例、代理、登录和加密 AI 配置。
- 当前 DSH 上游版本为开发者预览，依赖已锁定。能力范围以千面内置说明书为准；不会因此获得任意 Windows 桌面、系统命令或文件写入权限。
- AI 请求会附带用量统计参数；个别不支持的服务会自动去掉后重试。上下文窗口为估计值时，圆环标注「估算」。
- AI 操作网页和管理实例仍需实际验证结果，不保证所有第三方模型、网站或扩展兼容；不同模型服务可能产生调用费用。
