# 千面 Facet v0.2.20

本次将内置 AI 的执行引擎接入 DeepSeek 官方开源 DSH，并补齐持续操作时的消息追加、待办和运行状态。

## 本次更新

- **接入官方 DSH**：使用官方 AgentLoop、工具注册、Session 和插件上下文驱动模型与工具；沿用千面的模型接口、实例控制、网页操作及权限边界。继续支持自选模型，无需安装额外 CLI 或启动其他服务。
- **执行中继续输入**：默认「接着做」将消息加入待办；「立即补充」在下一步提供最新要求，不撤销已执行的动作。待办支持图片和移除，按会话独立保存。
- **停止后的控制更清楚**：停止、失败或计划未完成时暂停后续待办，提供「继续处理」「继续待办」入口。重启后恢复历史与待办，等待手动继续，不自动恢复旧的完全权限。
- **进度与阅读体验**：显示引擎、当前工具和执行轮数，工具摘要使用中文；支持复制消息、回到最新消息以及返回运行会话。保留 Enter 发送、Shift+Enter 换行、模型选择和分会话草稿。
- **执行与恢复修复**：未知工具、参数校验失败也受无进展保护；连续截图只发最新画面，历史保留位置说明且不保存网页截图；退出时等待 Agent 停止并保存会话。
- **旧计划与当前任务分开**：历史计划折叠标记为未核对，问候不会恢复旧任务或沿用旧实例数量；当前已授权计划未完成时追加有界的收尾检查，受阻或未完成明确暂停，支持继续旧任务。
- **扩展默认启用**：扩展中心可设置新建实例默认携带的扩展，普通、批量及 AI 创建保持一致；已有实例按原配置保留。
- **后台标签兼容**：修复重启、环境覆盖关闭及仅调整时区等路径下后台网页策略未完整恢复的问题。

## 升级说明

- Windows x64。正常退出并重新启动千面后加载新的执行引擎；保留已有实例、代理、登录和加密 AI 配置。
- 当前 DSH 上游版本为开发者预览，依赖已锁定。能力范围以千面内置说明书为准；不会因此获得任意 Windows 桌面、系统命令或文件写入权限。
- AI 操作网页和管理实例仍需实际验证结果，不保证所有第三方模型、网站或扩展兼容；不同模型服务可能产生调用费用。
