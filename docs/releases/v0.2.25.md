# 千面 Facet v0.2.25

本次重构内置 AI 助手界面与多会话并发引擎，新增实例分组与拖拽排序，并修复新建标签地址栏焦点、高频状态更新闪烁及窄屏表格挤压问题。

## 本次更新

- **内置 AI 助手双栏重构与多会话独立并行**：
  - 全新双栏布局：左侧可折叠会话管理栏 + 右侧极简对话与底部圆角输入卡片，支持左边缘拖动调整面板宽度并跨重启记忆。
  - 输入区直接支持选择模型与推理强度（`自动 / 低 / 中 / 高`，不支持 `reasoning_effort` 的接口自动兼容降级）；历史计划不再展开霸占对话区。
  - 默认操作权限调整为「完全权限」（免逐项弹窗确认），仍可按需手动切换「逐项确认」或「仅可查看」，并按会话持久化保留。
  - 真正的多会话独立并行：每个会话拥有独立的运行状态、实例授权范围与任务上下文，可同时在不同会话里操作不同实例互不锁死；发起新任务时自动清空上一轮旧计划避免串台。
  - 工具调用升级：为 `list_instances`、`show_instance`、`start_instance`、`stop_instance`、`navigate`、`reload` 拆分独立强类型参数定义，新增 `manage_tabs` 管理实例内多标签，为 `act` 补充 `back` / `forward` / `wait`，并放开并行工具调用上限至 6 路。
- **实例分组与拖拽排序**：
  - 支持在「实例管理」新建自定义分组、批量/单项或拖拽将实例移入分组，支持按分组筛选与「启动本组 / 停止本组」。
  - 支持拖拽或快捷键（`Alt + 方向键`）调整分组顺序与实例行顺序，筛选状态下保留隐藏行原位置，重启后完整恢复。
- **地址栏与新建标签页焦点修复**：
  - 修复点击 `+`、按 `Ctrl+T` 或关闭最后一个标签补开新标签页时，默认页加载前后地址栏无法直接输入、加载完成被页面搜索框抢走焦点的问题。
  - 修复网页内按 `Ctrl+L` 未将原生键盘焦点交回控制窗口地址栏的问题。
  - 浏览页改为同实例就地增量更新，保留地址栏与查找框 DOM 节点，消除状态刷新时的输入框外框闪烁。
- **实例管理防闪烁与响应式适配**：
  - 「实例管理」页、顶栏运行中标签、左侧边栏和标题栏改为内容变更检测与按行就地增量更新，在共享节点端口同步或其他实例加载网页等高频状态推送期间，按钮不再闪烁、不再丢失点击。
  - 基于主内容区实际宽度启用 CSS 容器查询（`@container`），展开或拖宽右侧 AI 面板时自动分级隐藏次要列并保持状态筛选栏单行不折字，彻底避免列文字重叠。
- **项目主页预览图**：在 `README.md` 补充黑金深色与日光浅色双主题的界面预览图（采用隔离演示数据生成）。
