# 千面 Facet 0.2.19

2026-10-23 · Windows x64。

本次主要加入实例内多网页标签和节点端口共享代理，完善随机创建流程，并修复后台白屏、导航取消误报及资源统计问题。

## 本次更新

- **实例内多网页标签**：同一实例支持最多32个网页标签，共享该实例的登录、网站存储、代理和浏览环境；不同实例继续隔离。支持新建、关闭、切换及常用键盘快捷键。重启恢复网页列表、顺序和活动页，其他网页选中后加载。
- **浏览工具栏整理**：顶部保留横向实例切换栏，实例网页标签放在地址栏上方；收藏和检测入口收纳为菜单，开发者工具入口简化为F12。普通新窗口链接可打开为同实例标签，独立弹窗沿用现有处理。
- **节点端口共享代理**：代理管理提供“实例独立代理”和“节点端口共享代理”两种互斥模式。共享模式按节点完整配置及网络策略复用代理核心，并为节点保存本机监听端口；同节点可供多个实例使用，网站存储仍按实例隔离。模式切换后尝试恢复原先运行的代理实例，失败项单独报告。
- **节点来源与端口展示**：节点列表补充订阅来源、实际本机代理端口及运行状态，压缩信息行；节点操作后保留列表滚动位置，便于管理大量节点。
- **随机创建避免重复分配**：普通新建、批量创建及AI随机创建统一排除已分配的节点配置。批量创建默认在最近连通检测可用的未分配节点中随机选择，本批不重复；节点不足时提示。需要复用时可明确选择按顺序循环分配，手动指定节点仍可复用。
- **创建取消与结果校验**：取消批量创建时，中断尚未写入的出口查询，保留已创建实例；退出应用后，未完成的创建请求不再继续保存。写入前重新核对节点来源及配置，防止使用查询期间已被删除或更新的旧节点。
- **后台白屏修复**：修复最小化、切换实例或标签后，动画帧暂停导致页面加载完成却不显示内容的问题；补齐最小化时新建标签的视口初始化。恢复窗口及运行中切换保持同一网页，宫格显式省资源模式继续保留节流。
- **导航取消不再误报**：页面资源仍在加载时，可继续点击收藏或检测入口切换网站；被新导航替代、站点脚本跳转等取消场景不再误报ERR_ABORTED，真实网络失败仍提示。
- **订阅连接兼容性**：订阅域名存在多个通过安全校验的公网地址时，连接层可尝试其他地址，避免首个地址不通即失败；全过程仍共用20秒上限。下载或解析失败保留原订阅，错误提示补充具体连接原因。
- **资源读数补齐**：Windows顶部CPU统计加入本应用启动的代理核心、进程保护与采样辅助进程；共享进程在总数中去重，按使用它的运行实例数分摊展示。内存继续使用私有提交量，采样不完整时明确标记。

## 升级与使用

- Windows x64。正式更新后需要正常退出并重启千面，主进程修复才会生效；刷新网页不能替代应用重启。
- 保留已有实例、登录存储、扩展、代理与环境配置。重启或切换代理模式前保存未提交的网页输入；网页内存和未提交输入不支持跨进程恢复。
- 节点代理端口仅监听本机，随千面关闭而停止。共享代理核心不代表实例共享Cookie或网站存储，也不保证不同节点拥有不同出口IP。
- “最近检测可用”不是实时连通保证。后台持续渲染可能增加资源消耗；宫格省资源模式仍可能暂停或降低后台网页运行速度，系统睡眠和应用退出也会中断任务。

- 已完成本轮源码及权限边界检查（333个脚本）、控制API回归（1项）、后台/最小化专项（7项）、导航回归（6项）和宫格切换回归（4项）。
