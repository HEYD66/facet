# 千面 Facet 0.2.17

千面是一款以用户隐私保护为核心、内置 AI 助手的开源多实例浏览器：通过独立会话、可配置环境与代理管理区分不同用途的浏览活动，让 AI 按授权协助操作实例和网页。

## 本次更新

- **扩展 ZIP 导入**：扩展中心可直接选择 ZIP，支持根目录或唯一嵌套目录中的扩展；沿用权限确认，导入后默认不启用。保留解压目录导入，并支持从原 ZIP 更新和更新并重启。
- **扩展规则生效修复**：修复网页诊断监听导致扩展 DNR 拦截、重定向及修改请求/响应头规则不执行的问题；启动时补齐 manifest 默认启用的静态规则集，保留扩展自己的启用选择。
- **环境重置完善**：通过当前网络重新查询出口，匹配语言与时区；查询失败保留原实例。重建使用新 ID、新存储分区和新随机环境，保留名称、代理及扩展启用列表，清除旧登录和扩展数据，支持单项及批量操作。
- **网页复制修复**：允许网页向剪贴板写入文本、HTML 等内容，修复复制按钮报错或无响应；剪贴板读取仍默认拒绝。
- **备注编辑修复**：在备注框内拖选文字、松开到框外时不再误关弹窗，避免未保存内容丢失。
- **项目介绍更新**：首页与应用介绍突出隐私保护和内置 AI，补充数据存储、模型服务的数据去向及隐私边界说明。

## 使用说明

- 内置 AI 支持自选模型、图片输入、流式回复、多会话和持久上下文。模型服务由用户配置，任务涉及的网页内容、图片、上下文和工具结果会发送给所选服务；未配置服务时不发送 AI 请求。
- 实例资料和配置保存在本机，AI 密钥与会话使用系统加密。会话隔离与环境配置不保证完全匿名、不可追踪或零泄露。
- 环境重置会清除旧登录与扩展存储，备注、自启动等恢复默认；外部脚本需要改用新实例 ID。
- ZIP 导入有路径、格式和大小校验；本版仍不支持 CRX、商店直装或全部 Chrome 扩展 API，不保证所有插件和网站兼容。
- Windows x64 安装包，复用现有 Electron 与 Mihomo 内核；升级保留已有数据。本版不包含未完成的订阅指定代理功能。
