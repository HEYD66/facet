# 千面 Facet 0.2.13

本次更新扩充环境随机方案，补充常用扩展接口，修复 Windows 任务栏图标显示，并补全问题诊断日志。

## 环境配置

- 新增“扩展设备库 · 整套随机”，包含 482 条规范化 GPU 候选及 13 套屏幕/DPR 组合，按组合规则生成硬件配置。
- 普通“一键随机”也使用新设备库生成显卡、CPU、内存等配置，保留当前视口、屏幕和 DPR；新建、批量创建和环境重置使用整套生成方案。
- 同一种子和库版本可复现，已保存环境不会因升级重新随机；保留原有设备预设、代理及语言/时区设置。

## 扩展兼容

- 补充框架查询、标签与窗口、通知、下载、Cookie、书签、历史、定时任务、工具栏状态、侧栏及实例内调试等常用接口。
- 扩展打开的网页沿用所属实例的会话、代理和环境；跨实例访问拒绝执行，停止实例时回收关联活动。
- 完善下载取消、同名并发文件、原生保存框及权限确认生命周期；兼容状态按实例保存，重启后保留已有持久数据。
- 修复 MV2 后台尚未就绪时的消息处理，保留明确的失败和超时结果。

## 图标与文档

- 修复开发启动时任务栏显示 Electron 默认图标的问题，统一主窗口、扩展窗口与任务栏的千面图标；正式包按实际安装路径加载。
- 补充项目总览、功能范围、API/AI 接手说明、专题文档及验证边界，安装包一并附带文档索引。

## 日志与问题反馈

- 修复“全部日志”实际只有操作记录的问题；按钮改为“导出操作记录”和“导出详细诊断包”。
- 诊断包加入订阅 DNS、连接、TLS、HTTP、解析结果和耗时，以及内核输出、网页失败和节点检测历史，便于定位失败环节。
- 调试输出跨重启保留，附故障索引、任务关联及容量/截断说明；自动脱敏，旧版未采集内容无法补回。

## 支持范围

扩展接口补充不等于兼容所有 Chrome 插件；CRX/ZIP 直装、本机辅助程序通信及部分高级参数仍有限制。指纹库用于配置生成，本版未重编译浏览器内核，Worker/WebGPU、字体和完整硬件能力覆盖仍有边界。订阅指定代理仍在开发，未纳入本次功能。诊断日志不包含普通网页控制台及请求/响应正文，也不保证所有故障都能仅靠日志定位。

## 安装

下载 `Facet-Setup-0.2.13-x64.exe`。升级前正常退出千面，安装保留已有实例、登录存储、代理和扩展配置；不会自动执行环境重置。安装包未签名，附带 SHA256 校验文件。
