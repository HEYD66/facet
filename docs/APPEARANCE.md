# 紧凑界面与夜间模式

## 当前摘要（2026-10-13）

v0.2.12 的应用设置分别选择日间/夜间配色，默认日光/黑金；顶部切换和侧栏折叠由控制界面保存偏好，不更改网页媒体偏好、节点或登录资料。网页自带主题和扩展是另外的作用范围。

浏览器网页由原生 WebContentsView 绘制，管理弹窗/菜单必须核对真实层级与可点击性；仅截图控制窗口或修改 CSS 不证明能覆盖网页。当前开发者工具在实例右侧并有拖动分隔条，宫格放大返回浏览页保留原网页。升级弹窗含更新内容、声明、项目地址和同行 Star 提示/强调按钮。

## 使用

右上角“夜间 / 日间”切换控制窗口主题；“侧栏”展开或折叠导航。首次默认日间，选择保存在控制窗口的localStorage（arena.ui.theme / arena.ui.sidebar），重开沿用。存储不可用时仍可切换，不阻止程序启动。偏好在样式加载前读取，避免已选夜间后重新打开先显示白色界面。

夜间模式覆盖控制栏、表单、表格、管理页、收藏与快捷网站弹窗等；不会调用Electron全局nativeTheme，不注入远程网页、不使用反色滤镜，不改变网站可见的媒体偏好或已配置指纹。网页若需要夜间外观，请使用网站自身的主题设置。

## 布局

- 品牌栏46px，实例标签36px；保留实例切换、关闭确认和新建入口。
- 默认侧栏196px（较窄窗口180px），可折叠为58px图标栏；按钮保留中文辅助名称和悬停提示。
- 当前实例卡片压缩为名称摘要；删除与“代理与指纹”重复的配置按钮，管理功能仍在原入口。
- 浏览页去掉重复标题、状态和外层边框；快捷网站保留且可横向滚动，地址栏和网页区域直接衔接。
- 原底部重复代理信息合并为一条状态栏，显示代理、语言/时区、视口模式，溢出悬停可查看。
- 不动画改变原生页面边界；侧栏折叠触发layout，ResizeObserver补充跟踪工作区尺寸；弹窗打开时仍隐藏原生WebContentsView。

## 实现和维护

appearance.js只管理控制窗口偏好与布局通知；appearance.css覆盖原布局；night.css显式覆盖旧样式中的硬编码颜色和状态色。新增控件应优先使用--panel / --panel2 / --text / --muted / --line / --red等变量，两套主题下复核。原网页背景不受这些控制窗口样式影响。
