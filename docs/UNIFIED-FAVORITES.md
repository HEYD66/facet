# 统一收藏夹与随机窗口保护

## 当前摘要（2026-10-13）

代理管理中的收藏夹整合节点引用与 IP 备忘；失效来源不会伪装为可用节点。节点引用不复制密码，分配明确更新目标实例副本并停止它；IP 备忘不改变任何网络模式。

普通“一键随机”在表单中保留窗口/屏幕参数，不清网站数据；v0.2.12 的“重置环境”停止目标、清除数据、保存新环境并开启桌面硬件覆盖，触摸点为 0。这两个入口不可混称。下方保留早期验证记录，当前流程见 [项目手册](PROJECT.md)。

2026-09-27。按用户要求：去掉的是重复入口，不删已有收藏或削减节点能力。

## 随机不再动窗口参数

“一键随机”保留当前视口宽高、DPR、屏幕宽高和可用高度，包括0×0自适应以及大于默认模拟屏幕的自定义视口。随机沿用有效的硬件/屏幕覆盖启用状态，避免首次随机额外启用屏幕覆盖。UA、平台、CPU、种子等其他随机项仍按既有规则生成，语言、时区、定位不变。

此限制针对随机操作；手动“填入设备预设”仍是明确应用设备方案。没有改写用户已保存的实例配置，也没有重启生产窗口。

## 唯一收藏入口

左侧全局管理不再显示“节点收藏”。代理管理内容右上角“收藏夹”整合两栏，数量与既有数据同步；旧内部收藏路由跳转至代理管理并打开节点栏。

### 节点收藏

- 节点名、协议、来源名称；来源失效/节点不可用有明确提示，禁用检测及分配。
- 最近连通性、出口IP及地区、下载速度；悬停查看时间、提供方和错误详情。不是实时状态。
- 单条连通性/IP/下载测速；选择筛选结果、批量连通性/IP与取消进行中的检测。下载测速只由用户手动确认触发，每次约5MB。
- 在收藏夹内选择目标实例并确认分配。只更新该实例的独立节点副本并停止该实例，不自动重启，不影响其他实例。
- 显示所有已关联实例名称、运行状态、直连/代理配置和副本同步状态；关联信息不等于当前正在使用该代理。
- 可按节点、来源、出口IP、已分配实例搜索；可定位原来源、取消收藏以及收藏检测到的IP。
- 全局检测任务互斥，不允许重复并发任务；失败不切为直连。

### IP 收藏

保留手动添加、IPv4/IPv6规范化、搜索、备注编辑、单条/批量复制、选择和确认删除。IP仅是地址备忘，不被当成可连接的代理。节点收藏和IP收藏原有持久化文件及数据不删除。
